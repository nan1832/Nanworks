# 我们的研究：固定训练预算下的视觉编辑层选择

> 整理日期：2026-09-29。用途：作为后续论文动机、方法、实验设计和相关工作部分的共同依据。
>
> 本文档区分“当前研究定义”“已核验的历史结果”和“待验证的贡献”。它不代表新增实验已经执行，也不修改既有训练配置。数值依据为下文注明的本地记录快照；后续新增结果应保留数据、预算、checkpoint 和方法版本信息再更新结论。

## 1. 核心定位

**我们的工作研究：在冻结视觉语言模型、固定视觉编辑 adapter、训练数据、训练方案和训练预算的条件下，如何在训练候选 adapter 之前，以较低定位成本推荐少量编辑插入层，使其在该预算内获得较好的编辑效果。**

当前主研究目标可以命名为：

- 中文：固定训练预算下的视觉编辑层候选推荐。
- 英文：Visual Editing Layer Selection under a Fixed Training Budget。
- 方法描述：基于新旧目标视觉表征梯度的候选层定位。

当前主协议为每个候选层训练至多 50 个 epoch，并按既定规则选择预算内 checkpoint。因此，我们研究的是**给定训练条件下的编辑适宜性**。适宜层可以依赖数据、编辑器、预算和评价目标，不必是一个不随训练过程改变的“知识存储位置”。

论文的中心问题应表述为：

> 预测贡献度、参数显著性和因果恢复等定位信号，在多大程度上能够预测固定预算内的视觉编辑效果？直接围绕视觉表征上的新旧目标梯度构造代理分数，能否在相同候选数量和训练预算下提供更有效的候选层？

这一问题允许实验得出“某些归因方法仍有用”“只在部分条件下改进”或“Top-3 稳定而 Top-1 改变”等结果，不需要预先以推翻 VisEdit 为成立条件。

## 2. 为什么这一问题有意义

视觉编辑器的插入位置会影响目标知识写入、泛化和无关知识保持。若每个插入层都需要单独训练 adapter，逐层试验的成本随候选层数增加。实际研究和部署通常只能承担有限的训练次数与单次训练预算。

这里存在两个不同的预测任务：

1. **解释原模型的预测**：哪些模块或表征对当前答案产生较大贡献？
2. **预测编辑干预的收益**：在某个位置训练指定 adapter 后，能否在给定预算内同时获得可靠性、泛化和局部性？

两者的评价对象不同，所以从第一种分数到第二种收益需要验证；但“对象不同”本身不构成二者一定无关的证明。归因仍可能提供有用的区域先验。

我们的实用价值在于：把需要昂贵训练才能知道的层质量，转化为一个可检验的低成本候选推荐问题。即使不同预算下最优单层不同，只要少量推荐层能够在目标预算下获得接近参考最优的效果，仍具有明确的计算价值。

## 3. 对 VisEdit 的准确理解，以及我们真正检验什么

VisEdit 的第一类归因分析考察 Attention/MLP 输出对关键 token 预测的贡献；其编辑器据此放在高贡献层之前。论文 §4.2 描述了这一设计，Table 2 将 BLIP2 的 L19 标为归因分析选出的层，并用不同插入位置的实验验证设计。[VisEdit 原文](https://arxiv.org/html/2408.09916v3)

因此，下列三个命题必须分开：

| 命题 | 如何检验 | 结果能够支持什么 |
|---|---|---|
| A：贡献越高的层，本层插入 adapter 的效果越好 | 对 Attention、MLP、二者组合的直接分数，计算同层质量相关性及直接 Top-K 质量 | 判断直接排序的预测能力 |
| B：高贡献区域之前，是有用的插入区域 | 明确高贡献区判定与前置映射，评价 VisEdit-style Pre 候选 | 判断归因引导区域选择的实用性 |
| C：我们的梯度代理在固定预算下推荐得更好 | 相同数据、编辑器、预算和 K 下比较候选质量与成本 | 判断新方法相对基线的收益 |

**A 不成立，不自动意味着 B 不成立；C 成立，也不要求 B 完全失效。**

“Attention 贡献”“MLP 贡献”“Attention+MLP 贡献”是三种信号构造，可以分别用于直接排序诊断和 Pre 策略。组合方式、归一化、阈值、连续区域识别、边界与并列处理都应在验证前冻结。

VisEdit 论文中的归因启发，不应被改写成“原始贡献最大的位置就是最优插入位置”。同样，项目为了自动输出 Top-K 而定义的阈值和映射，是对论文思想的具体实现；不能将所有实现细节都称为作者原始算法。

项目中 VisEdit 的 alt 与 model_pred 目标版本要分开报告。原模型关键预测、编辑后目标关键 token 与完整目标序列，回答的问题不同。已有 VisEdit-alt 比较不能自动代表新增 model_pred 版本的效果；定位阶段使用 FirstToken/KeyToken，也不意味着最终编辑评测只评一个 token。

## 4. 与直接相关工作的区别

下表用于界定最接近的先行工作，不是穷尽性文献综述。

| 工作 | 已有研究的核心内容 | 我们的具体研究空间 |
|---|---|---|
| VisEdit | 将归因观察用于视觉编辑 adapter 的位置与设计，并进行位置验证 | 固定同一编辑器，系统检验多种定位规则在相同预算下的 Top-K 推荐质量；关注位置选择，而不将整个编辑器重新作为创新 |
| Does Localization Inform Editing? | 在语言模型中研究因果定位与实际编辑效果的关系，发现其所研究的定位结果不足以预测最佳编辑层 | 将问题落实到视觉表征 adapter 干预、有限训练预算和候选推荐，并提出可验证的视觉梯度代理 |
| SaLEM | 利用层级参数梯度显著性选择编辑层，并与 MEND 编辑结合 | 比较参数显著性与视觉 hidden-state 梯度；保持下游视觉 adapter 相同以隔离选择规则 |
| Golden Layers / LGA | 研究少数固定层与逐样本最优层的关系，并利用新旧目标参数梯度进行低成本选层 | 研究视觉表征插入位置及其预算内训练收益；检验视觉表征梯度相对参数梯度的增量价值 |

参考原文：[VisEdit](https://arxiv.org/html/2408.09916v3)、[Hase et al., NeurIPS 2023](https://arxiv.org/abs/2301.04213)、[SaLEM, Findings of EACL 2024](https://aclanthology.org/2024.findings-eacl.86/)、[Golden Layers / LGA, arXiv v3](https://arxiv.org/html/2602.20207v3)。

### 4.1 已有工作覆盖了哪些宽泛主张

“定位结果不必对应最佳编辑位置”已经有直接先行研究；“利用梯度选择编辑层”“用少数固定层减少搜索”也已经被研究。因此，本工作不能仅凭这些宽泛表述主张首次提出。

我们需要证明的增量是：**干预对象相匹配的视觉表征梯度，在固定视觉 adapter 与预算的条件下，能否比已有定位信号更有效地推荐候选位置。** 多模型、多数据集是检验这一问题的证据范围，数量本身不替代方法贡献。

### 4.2 基线的命名和复现边界

- SaLEM-based：移植其层选择信号，后续统一训练视觉 adapter；不称为完整 SaLEM 编辑器复现。
- LGA-Param-Tukey：使用 MLP/FFN weight 上的新旧目标参数梯度及 Tukey 筛选；历史 Raw 版本单列消融。LGA v3 附录 A 包含异常层过滤，默认常数为 1；项目的 linear 分位数规则是显式实现选择。[LGA 附录](https://arxiv.org/html/2602.20207v3#A1)
- CMA：项目中的视觉污染—恢复定位适配，区分 alt/model_pred 及其有效样本覆盖；不因使用恢复思想就称为完整复现所有因果定位或参数编辑方法。
- Perturb-KL：项目构造的视觉表征扰动、完整目标序列分布敏感性基线，应明确其为自行实现的对照。
- Middle-layer Prior 和随机候选：检验复杂定位能否超过简单结构先验，随机候选需重复抽取以得到分布。

本地总手册中保留了部分旧版 LGA Raw 描述。论文应采用已更正的 [Tukey 补正手册](<D:/开题/正式开题/Model Edit/bli2-reasonvqa/dataset/md/Location/Equations/LGA-Param-Tukey_候选层补正手册_20260926.md>)，不能继续用旧 Raw 结果代表完整 LGA 基线。

## 5. 形式化研究范围：预算进入质量定义

设冻结骨干为 \(F\)，视觉编辑器结构为 \(E\)，候选插入位置为 \(\mathcal L\)，训练集为 \(D_{\mathrm{tr}}\)，训练方案为 \(R\)，随机种子为 \(s\)。

项目采用 0-indexed 层号。位置 \(l\) 表示 decoder block \(l\) 输出之后、block \(l+1\) 输入之前的视觉表征干预位置。跨论文比较时应同时核对 hook 位置与编号，不能只比较层号数字。

训练预算 \(B\) 下，按预定 checkpoint 选择规则得到：

\[
\widehat\phi_{l,B,s}
=\operatorname{Select}_{R}
\left\{\phi_{l,t,s}:t\leq B\right\}.
\]

预算内的实际编辑质量为：

\[
Q(l,B,s)
=\operatorname{Eval}
\left(F,E_l(\widehat\phi_{l,B,s});D_{\mathrm{eval}}\right).
\]

这里省略的 \(F,E,D_{\mathrm{tr}},R\) 均是条件，不能在对照中任意变化。当前 checkpoint 规则为训练预算内按最小 EMA loss 选择；不能把它写成“统一使用第 50 轮 checkpoint”，也不能按测试集分数重新挑 checkpoint。

在参考层集合 \(\mathcal U\) 上：

\[
Q^*_{\mathcal U}(B)=\max_{l\in\mathcal U}\mathbb E_s[Q(l,B,s)].
\]

若只有一次训练，记录的是单次观测值，而不是已估计的跨种子期望。若 \(\mathcal U\) 仅为候选层并集或已测层集合，称为 Candidate-union / Measured-layer Oracle；只有覆盖全部合法候选位置时才称 Full-layer Oracle。

### 5.1 “50 轮固定预算”的准确含义

- 同一模型与数据组合内固定训练数据、batch size、采样、优化器、学习率安排与训练上限，再比较不同层。
- 相同 epoch 数跨数据集不等于相同训练步数；跨模型、跨层也不必等于相同 GPU 时间。正式记录同时列出 epoch、update steps、有效 batch、样本曝光量和实际耗时。
- 当前研究定义是固定训练协议下的比较；若要声称相同计算成本，需要额外按 GPU 时间或其他明确计算预算核对。
- 当前梯度分数不以 \(B\) 为输入，所以它是“在预算 \(B\) 下验证的选择器”，尚不是能够自动适配任意预算的选择器。
- “定位阶段无需训练 adapter”不等于零成本；生成旧答案、前向、反向、缓存和排序均计入定位开销。

## 6. 当前视觉梯度方法：可用于方法部分的定义

以下依据现有公式手册记录当前主版本，不在本文档中设计或替换新公式。

### 6.1 输入与梯度

对定位集样本 \(i\)，输入 \(x_i\) 包含图像和问题。新目标 \(y_i^{\mathrm{new}}\) 使用 alt；旧目标 \(y_i^{\mathrm{old}}\) 使用冻结模型确定性生成并缓存的 model_pred。

model_pred 表示模型在指定解码配置下的输出，不等于真实旧事实。需要记录最大生成长度、停止条件、空输出与截断情况；数据字段 pred 仅作为另行命名的附加版本，不能与 model_pred 混用。

对新旧目标分别使用长度归一化 teacher-forcing NLL：

\[
\mathcal L_i^a
=-\frac{1}{|y_i^a|}
\sum_{t=1}^{|y_i^a|}
\log p_F(y_{i,t}^a\mid x_i,y_{i,<t}^a),
\quad a\in\{\mathrm{old},\mathrm{new}\}.
\]

仅答案 token 参与 loss，prompt、visual tokens 与 padding 不参与损失平均。在 decoder block 输出的视觉 token 位置接入零扰动 \(\Delta^v_{i,l}\)，分别求：

\[
g^a_{i,l}
=\operatorname{vec}\left[
\left.\frac{\partial\mathcal L_i^a}
{\partial\Delta^v_{i,l}}\right|_{\Delta^v_{i,l}=0}
\right].
\]

这与相应视觉 hidden states 的梯度等价。梯度对象是视觉表征，不是 Attention/MLP 权重，也不是训练后 adapter 参数。

### 6.2 聚合与当前主分数

先对每个样本计算：

\[
c_{i,l}
=\frac{\langle g^{\mathrm{old}}_{i,l},g^{\mathrm{new}}_{i,l}\rangle}
{\|g^{\mathrm{old}}_{i,l}\|_2\|g^{\mathrm{new}}_{i,l}\|_2+\epsilon},
\qquad
n_{i,l}=\|g^{\mathrm{new}}_{i,l}\|_2.
\]

当前手册 \(\epsilon=10^{-8}\)。在有效样本集合 \(I_l\) 上分别取均值：

\[
C_l=\frac{1}{|I_l|}\sum_{i\in I_l}c_{i,l},
\qquad
N_l=\frac{1}{|I_l|}\sum_{i\in I_l}n_{i,l}.
\]

当前主公式 Ours-Direct / M_abscos_x_newn 为：

\[
S_{\mathrm{ours}}(l)=|C_l|N_l,
\qquad
\mathcal C_{\mathrm{ours}}^K
=\operatorname{TopK}_{l\in\mathcal L}S_{\mathrm{ours}}(l).
\]

排序直接对应 adapter 插入位置，不做额外 Pre 偏移，不含深度权重。有效性过滤与并列规则以冻结实现为准，并保存有效样本数。

特别注意：这是**先平均余弦与范数，再取绝对值并相乘**，不等于逐样本 \(|c_{i,l}|n_{i,l}\) 的平均，也不等于参数梯度内积。正负余弦可在平均时相互抵消；绝对值又不区分最终均值的正负方向。因此，主公式不能称为“严格冲突分数”。

### 6.3 方法动机及其可支持的解释

视觉编辑 adapter 实际修改视觉表征；相应 hidden-state 梯度反映目标损失对这些表征的局部敏感性。新目标梯度强度与新旧目标方向关系，因此是值得验证的选层信号。

一阶近似：

\[
\mathcal L(h^v+\delta)-\mathcal L(h^v)
\approx \langle g,\delta\rangle
\]

只描述局部扰动。训练后的 adapter 能实现何种扰动还受其参数化、数据和优化过程影响；通过链式法则，adapter 参数梯度还取决于相应 Jacobian。主分数不直接包含完整训练动力学或 locality 约束，所以最终综合收益必须通过真实编辑验证，不能从该近似推出最优层定理。

核心消融包括：仅新目标范数、仅方向分数、有符号/绝对值/负方向关系、参数梯度与视觉表征梯度、是否使用深度权重，以及样本量和目标来源。保留原始公式名和版本，避免结果出来后无记录地改公式。

### 6.4 公式选择的历史必须保留

本地总手册 §6.9 明确记载：主公式是在已有真实 adapter sweep 比较后，从候选公式中选出的。其余 10 个公式保留为消融与诊断。

因此，现有用于选公式的结果属于方法开发证据。论文可以用它们说明设计过程，但不能同时将它们全部描述为完全独立的预测验证。后续应冻结公式、阈值、K 和过滤规则，在未参与选公式的组合、预留数据或预先划定的外层验证中评价。

仅换随机种子可以检验训练稳定性，却不能消除已经针对同一批组合选公式所产生的选择偏差。若所有现有组合都参与过选择，应如实标注，并增加独立验证条件。

## 7. 统一实验流程与评价

### 7.1 定位、训练、选择与测试分工

1. 定义定位/开发数据、adapter 训练数据、验证数据和最终测试数据的角色，冻结样本标识和版本。定位可以使用训练侧数据，但不可用最终测试效果反复改公式。
2. 各定位方法在允许的相同输入范围上计算分数，输出 Top-1/3/5 和有效覆盖。记录方法内部过滤，不把“共同输入数”等同于“有效样本数”。
3. 对去重候选并集中的每个层，分别初始化并训练同结构 adapter，使用相同训练方案与预算；相同层的训练结果可以供多个选择器共享。
4. 各层按统一的预算内 checkpoint 规则取模型。main、stable、rerun 等不同训练方案分别比较，不用成功重跑静默替换主协议下的失败。
5. 在候选集内部需要选出最终部署层时，仅用验证集选择，然后在未参与选择的测试集报告效果。
6. 保存推荐集合、训练日志、checkpoint 路径、逐样本评价与汇总分数，使选择过程可复核。

“同一个已训练 checkpoint 改挂到其他层”测量的是迁移挂载的效果；“每个层分别训练 adapter”测量的是各位置的训练适宜性。两类实验不能混为同一条扫层曲线。

### 7.2 实际编辑评分

现有 VisEdit 评价代码的 Rel、T-Gen、M-Gen 使用 teacher-forcing 下答案有效 token 的 argmax 准确率；不是自由生成整句精确匹配、语义裁判评分或仅首 token 评分。每条评价输入先计算有效 token 平均，再在对应类别记录上聚合；若一个编辑样本有多个泛化/局部性条目，要保留代码中的条目权重。

T-Loc、M-Loc 比较相同输入下编辑前后有效答案位置的 token 预测是否一致，不是评价 locality 参考答案的正确率。评价时对每个编辑样本单独建立编辑信号，完成该样本及其邻域测试后恢复编辑状态。

\[
Q=\mathrm{Average}
=\frac{\mathrm{Rel}+\mathrm{TGen}+\mathrm{MGen}
+\mathrm{TLoc}+\mathrm{MLoc}}{5}.
\]

本项目汇总表使用百分制。Average 应同时附五项明细；例如 T-Loc 恒为 100 时不能据此判断全部知识都得到保持，层间差异还需看其他项目。

实现依据：[本地 evaluator](<D:/开题/正式开题/Model Edit/bli2-reasonvqa/dataset/VisEdit-main/evaluation/vllm_editor_eval.py>)；[官方 evaluator](https://github.com/qizhou000/VisEdit/blob/main/evaluation/vllm_editor_eval.py)。论文抽象定义与实现细节不同层次的表述，应以实际运行代码说明本项目分数。

### 7.3 候选质量指标

对选择器 \(m\) 的 \(K\) 个候选 \(\mathcal C_m^K\)，在相同预算和种子汇总规则下定义：

\[
\mathrm{Best@K}_m(B)=\max_{l\in\mathcal C_m^K}Q(l,B),
\quad
\mathrm{Mean@K}_m(B)=\frac{1}{K}\sum_{l\in\mathcal C_m^K}Q(l,B),
\]

\[
\mathrm{Regret@K}_m(B)
=Q^*_{\mathcal U}(B)-\mathrm{Best@K}_m(B).
\]

除原有 Hit@K 定义外，可预先指定允许差距 \(\delta\)，新增并明确命名为：

\[
\mathrm{Hit}_{\delta}@K
=\mathbb I\{\mathrm{Regret@K}\leq\delta\}.
\]

\(\delta\) 的单位为百分点，不能看到结果后选择最有利的阈值。精确命中与容差命中应分开，以免把相近层之间的微小名次差异夸大为失败。

- Top1Perf：直接使用定位排名第一层的效果，反映无需后续搜选的推荐质量。
- Best@K：候选集包含好层的能力；若用测试分数取最大，只是候选集诊断上界，不是无测试信息条件下可直接实现的最终成绩。
- Mean@K：候选集整体质量，避免只命中一个好层掩盖其他差候选。
- Validated@K：建议增加的实际选择指标；验证集在 K 层中选层，报告该层测试分数。它与测试 Best@K 分开。
- Spearman/Kendall：解释整体排序关系，但低相关不等于 Top-K 无效；恒定序列的相关系数未定义，不填 0。

参考集合 \(\mathcal U\) 应包含所比较方法的候选，并报告覆盖范围。Top-K 有缺失评测时标为未完成；不把缺失当 0，也不把剩余层均值写成完整 Mean@K。方法汇总采用共同可比组合，并另报各方法完整覆盖率。

### 7.4 成本与统计证据

定位方法的实际搜索成本应计为：

\[
\mathrm{Cost}_m
=\mathrm{Cost}_{\mathrm{loc},m}
+\sum_{l\in\mathcal C_m^K}\mathrm{Cost}_{\mathrm{train}}(l,B)
+\mathrm{Cost}_{\mathrm{validation}}.
\]

共享候选结果是构建研究基准时的节约；比较各选择器部署成本时，应分别计算其候选所需训练，不能给共享结果错误地记零成本。

报告独立训练种子的均值与标准差，并可对相同评价样本做配对不确定性分析。单次测试样本 bootstrap 不能替代训练种子变化。计划中的多种子协议，在执行前不得写成已完成实验。

若要声称“更快收敛”，需要训练过程中的验证质量—步数/时间曲线或达到同等质量的时间；单个 50 轮终点只能直接支持“该预算下效果更好”。

## 8. 当前证据如何影响研究表述

本节结果来自 2026-09-28 本地扫层账本及已存的 full-EVQA 记录，是研究定位的事实依据，不是新的全量实验结论。

### 8.1 BLIP2：现有结果不能用于宣称 VisEdit 区域启发失效

E-VQA pilot500、BLIP2、main 协议、50 轮预算，测试 2,093 条。与用户提供的论文表共同的七个层如下：

| 插入层 | 本地 pilot500 Average | 用户提供的论文 Average |
|---:|---:|---:|
| 0 | 58.164 | 93.55 |
| 5 | 68.890 | 94.16 |
| 10 | 73.088 | 94.72 |
| 15 | 73.038 | 96.89 |
| 19 | 74.852 | 97.53 |
| 25 | 70.784 | 95.80 |
| 30 | 53.642 | 88.00 |

共同七层的历史比较为 Spearman 约 0.893。它说明这两组结果在已比较层上具有相似的粗粒度排序，不能证明所有层、模型或预算均一致。

本地该组合已记录的 20 个 main 层中，L17 为 75.596，L14 为 75.192，L19 为 74.852。L19 仍处于前三，与 L17 相差 0.744 个百分点。最佳单层不同，可以提出精细选层问题；这一例子本身不足以否定“高贡献区域之前”的推荐价值，也尚不足以证明差距超出训练随机性。

同一组合不同指标的最佳层也可能不同。综合分数的最优层不能直接称为“最容易写入知识的层”，因为 Average 同时奖励保持原行为。

### 8.2 全量训练 50 轮与“126 轮”必须分开

已存 BLIP2 full-EVQA 记录使用 6,345 条训练数据、batch size 2、50 轮预算、2,093 条测试数据：

| 层 | 所选 checkpoint epoch | 由已记录五项百分制分数计算的 Average |
|---:|---:|---:|
| 17 | 46 | 96.724 |
| 18 | 50 | 97.156 |
| 19 | 49 | 96.160 |

这里只有三个中间层，L18 在这三层中最好；不能据此声称它是全层最优，也不能从这三点推出完整曲线。

论文公开训练设置为最大 200K iterations、batch size 4，并从保存的 checkpoint 中选最低 loss 者。将最大步数按训练集大小换算成约 126 个 epoch，只是预算量级换算，不能证明表中结果来自第 126 轮 checkpoint，亦不能证明已经收敛。[VisEdit 训练设置，附录 B](https://arxiv.org/html/2408.09916v3#A2)

因此，“我的 50 轮最佳 L17，作者 126 轮最佳 L19”目前是不同协议结果的比较。训练数据量、总步数、batch、种子和 checkpoint 规则等条件并未构成受控对照，不能写成已经验证的“延长训练导致最优层由 17 迁移到 19”。

### 8.3 LLaVA 的已有结果如何归类

本地已有 official 目录下的 E-VQA 2,093 条评价记录，汇总为 Rel 95.73、T-Gen 94.01、M-Gen 94.40、T-Loc 100.00、M-Loc 91.78，按已舍入汇总值计算 Average 为 95.184。

它证明本地存在接近论文量级的历史完整测试结果。但结果 JSON 本身没有完整的 checkpoint 路径与训练运行绑定，因此不能仅凭该文件把它标为本项目自行全量训练的结果，更不能用它证明跨预算层排名。原始逐样本重算与舍入汇总平均可能有微小差异，正式引用需固定口径。

另外，当前 LLaVA pilot500 已测 main 层中较优位置并不与 BLIP2 完全相同；不应把 BLIP2 的中层趋势当作所有骨干的既定结论。

## 9. 如何处理训练程度：主实验与最小预算敏感性实验

### 9.1 当前可以完成的主研究

将论文主问题限定在 \(B=50\) 的既定训练协议。所有选择器面对相同候选数量、训练条件和指标，比较该预算内效果。这是一个完整的研究问题，无需先证明无限预算下的最优层。

固定预算应作为研究设计事先明确，而不能因为某个预算结果有利才只展示它。历史上已经查看的预算和组合，需按开发证据记录。

### 9.2 建议的最小增补：尚未执行的计划

为了解结论是否过度依赖 50 轮，可先选择 2–3 个代表性模型—数据集组合，而不立即对 21 组全部重跑。组合选择规则提前写清，兼顾已有方法一致与分歧、不同骨干及任务类型。

每组固定数据、batch、优化器、学习率安排和种子，预先冻结去重后的候选集合，例如：

\[
\mathcal U_{\mathrm{budget}}
=\mathcal C_{\mathrm{ours}}^3
\cup\mathcal C_{\mathrm{VisEdit\text{-}Pre}}^3
\cup\mathcal C_{\mathrm{middle}}
\cup\mathcal C_{\mathrm{random}}.
\]

可用预算检查点为 50、100、150 轮；有完整保存条件时再加入 25 轮。准确预算值在运行前决定，不为得到某个最优层而调整。每个预算都按照“截至该预算的既定 checkpoint 规则”评价，而非只取长跑最终最佳 checkpoint 回填较短预算。

若采用同一长训练轨迹的前缀比较，学习率计划须从一开始保持一致。只有模型权重、没有 optimizer/scheduler/RNG 状态时，不能将续训直接视为完全等价的原轨迹延长。已有训练计划若依赖总 epoch 数，也应单列其影响。

报告 Top1、Best@3、Mean@3、Regret@3 与五项质量随预算的变化。候选集已经冻结时，不因看到新预算最佳层而回头改预测公式。跨预算比较仍只能覆盖实际测试的候选集合。

### 9.3 不同结果对应不同贡献表述

| 观察结果 | 合适的结论 |
|---|---|
| 在多个已测预算下均有较好推荐质量 | 在所测预算区间内表现稳健 |
| 小预算优势明显，较大预算优势缩小 | 对受限训练预算下的层选择有价值；优化效率解释需过程证据 |
| Top-1 变化，但 Top-3 持续覆盖高性能层 | 候选集合比单层精确预测更稳定 |
| 只在 50 轮有效，邻近预算也不稳定 | 结论限定于该协议，并分析依赖原因 |
| 多种方法均覆盖相近高性能区域 | 重点比较候选整体质量、方差和定位成本，而不强行声称推翻某方法 |

最优层随预算变化，在受控实验中被证实后可以成为额外的经验发现。当前不能把尚未测得的变化写成已完成贡献。

## 10. 可以构建的三项贡献及所需证据

| 贡献方向 | 论文可用的核心表述 | 成立所需证据 |
|---|---|---|
| 问题与经验分析 | 区分预测贡献和预算内编辑适宜性，评价定位信号对视觉编辑候选推荐的作用 | 直接排序与 Pre 分开检验，统一协议，覆盖和不确定性充分披露 |
| 选择方法 | 构造面向视觉表征干预的新旧目标梯度代理，训练候选 adapter 前生成少量候选位置 | 冻结主公式，独立验证，与参数梯度、贡献度和简单先验公平比较，完成关键消融 |
| 实用收益 | 在有限候选训练次数下取得较好的质量—搜索成本折中 | 相同 K/预算、真实时间或成本测量、验证集选层后测试；有条件时补充预算敏感性 |

当前可以确定的是研究定义、公式版本和已记录观察；“显著优于”“跨预算稳健”“降低了多少成本”等结果性措辞，须等相应证据完成后填写。

更稳妥的创新重点是**视觉干预位置与定位信号的匹配、受控的预算内验证以及实际候选选择收益**。最终贡献强度由这些证据决定，而不是由对 VisEdit 的否定程度决定。

## 11. 后续方法与实验章节的组织

### 11.1 方法部分

1. 问题定义：骨干、编辑器、插入位置、预算、固定训练规则、候选选择目标。
2. 目标构造：alt/model_pred、解码配置、teacher-forcing loss 与答案 mask。
3. 视觉梯度：具体 hook、visual span、零扰动求导、两次目标梯度与异常处理。
4. 层分数：逐样本统计、层级均值、主公式、Top-K 和并列/过滤规则。
5. 使用流程与复杂度：定位前后需要哪些信息，定位成本及只训练 K 个候选的流程。

### 11.2 实验部分

1. 设置：数据划分、7 个骨干与 3 类数据的实际完成范围、训练预算和 checkpoint 规则。
2. 对照：VisEdit-style Pre 与 raw 诊断、SaLEM-based、LGA-Param-Tukey、CMA、Perturb-KL、中层与随机。
3. 主结果：相同 K 下的候选质量和验证选层后的测试结果，并列五项编辑分数。
4. 分析：直接贡献与 Pre 的差异、梯度消融、覆盖率和不确定性。
5. 预算与成本：可执行的增补预算实验、实际搜索成本及训练过程证据。

当前项目覆盖的模型名称为 BLIP2-OPT-2.7B、InstructBLIP-Vicuna-7B、MiniGPT-4-Vicuna-7B、LLaVA-v1.5-7B、Qwen2.5-VL-3B-Instruct、PaliGemma-3B、SmolVLM-Instruct-1.7B。既有主协议的数据规模记录为 E-VQA pilot500：500/2,093；MMKE-Visual：214/293；MMKE-Entity：636/954（训练/测试）。

这些是实验范围与协议记录，不表示所有选择器候选、所有层或所有随机种子都已完成。最终正文只统计实际完成且可公平比较的实验。

### 11.3 可改写为论文动机的段落

> 视觉编辑 adapter 的插入位置影响其知识修正、泛化与局部性，但逐层训练以寻找合适位置代价较高。已有方法利用预测贡献、参数显著性或因果恢复信号辅助定位，这些信号与给定训练预算下的编辑收益之间的关系仍需在具体干预设置中验证。我们将该任务表述为固定训练预算下的候选层推荐，并考察新旧目标损失对视觉表征的梯度能否提供有效的选层依据。在统一视觉编辑器和训练协议下，我们比较不同选择器的候选质量与搜索成本，评价其在有限候选训练次数下的实用价值。

该段描述问题与方法，不预填实验胜负。后续结果完成后，再加入有明确适用范围和数值依据的发现。

## 12. 后续写作前的核对项

- 公式是先聚合后相乘，是否与实际运行代码一致；主方法名称与版本是否冻结。
- 哪些组合参与了公式选择，哪些构成独立验证；是否实际存在未参与调参的最终测试。
- 层号对应 block 输入还是输出，VisEdit-style Pre 的映射是否已经落实到相同坐标。
- epoch、step、样本量、batch、checkpoint 选择规则是否齐全；是否混入不同训练方案。
- Top-K 是否完整评价，参考 Oracle 是否仅为候选并集，缺失与不稳定结果是否单列。
- VisEdit-alt/model_pred、CMA-alt/model_pred、LGA Raw/Tukey 是否正确区分。
- Best@K 是否被误当最终可部署分数；是否提供验证选层结果与真实搜索成本。
- 训练种子是否确实重复；没有重复时不将小幅层间差异写成显著结论。
- 预算敏感性属于计划还是实测；没有输入预算的分数不称为预算自适应方法。
- 新增 VisualTrack 表征余弦等探索方向单独编号，不覆盖本文件记录的视觉梯度主版本。
