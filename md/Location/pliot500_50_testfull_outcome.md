## pliot500-epoach50-test-outcome

### 当前结论标记

本轮 `BLIP2 pilot500 VisEdit sweep` 中，`L5/L10/L15/L19` 当前训练结果标记为：

```text
实现疑似失效 / 需重跑
```

排查依据：
- checkpoint 内部保存的 adapter key 分别为 `language_model.model.decoder.layers.5/10/15/19`，因此不是简单的层号写错或都挂到同一层。
- 原始 BLIP2 模型在 `VEAD.set_train()` 中执行 `requires_grad_(False)`，优化器只接收 `self.adaptors.values()`，因此不是原始模型被训练。
- 训练脚本顺序复用同一个 `vllm` 时，`VEAD.init_wrap_get_llm_outpt()` 只在第一次 editor 创建时 wrap；后续 editor 因 `vead_wrapped` 标记不会重新绑定 wrapper，导致 wrapper 仍闭包绑定首个 L0 editor。
- 因此 L5/L10/L15/L19 虽然 hook path 正确，但新 adapter 可能没有正确收到 `vt_range / inpt_has_img` 等状态，adapter 实际未按当前层正常激活。
- 现象上，L5/L10/L15/L19 的 loss 高位震荡，评测结果高度一致，符合上述失效模式。

处理策略：
- 修复训练脚本：每层训练使用独立进程/重新加载模型，或使 `get_llm_outpt` wrapper 每次绑定当前 editor。
- 修复 visual adapter forward：缺少 `vt_range` 时直接报错，不再静默跳过。
- 重跑 `L5/L10/L15/L19`，旧结果只作为 bug 记录，不参与最终层定位分析。
