## 2. 统一实验口径
- 训练：request-only；训练集只使用 `request` 字段。
- 评测：Same-Entity Full Metrics rephrase_split；`request` 是 sanity acc，`generality/locality/portability` 用同实体验证集构造。
- Checkpoint 选择：优先 `ema_loss=0.0003/0.0004`；最多 700 epoch；未命中标记 `MISS_TARGET`。
- 有效 winner 过滤：`checkpoint_status != MISS_TARGET` 且 `request_acc >= 0.9` 且 `generality_acc >= 0.8`。这会排除编辑失败但 locality 虚高的尾层。
- `CoreAvg4 = (request_acc + generality_acc + locality_acc + portability_acc) / 4`，与 text-only 手册中的 core average 口径一致。
- Hook 位置：`Bridge30_Virtual_DeltaH_LGA_计算手册.md` §15 已确认真实 VEAD adapter 与 Virtual Δh LGA 都在 layer output forward hook 上，即 after layer l。

#### 6.4.3 读数要点

- `M_dot` 原始 dot 不能直接当通用 golden-layer 指标：在 LLaVA visual/text 上它与 generality 强负相关，反而把高层排到前面；但在 BLIP2 的 locality/CoreAvg4 轴上会追踪后层。
- 视觉分支更需要“方向 × 杠杆”的复合指标：`M_newn_x_1mcos` 适合 LLaVA，`M_abscos_x_newn` 适合 BLIP2，Qwen2.5-VL 的 `M_cos` 更像精确层定位信号。
- 文本分支更接近浅层幅度信号：InstructBLIP text 的 `M_dot` 同时命中 Gen/Core；Qwen2.5-VL text 的 top-k 命中 layer 0，但相关性被 0-26 层高准确率平台稀释。
- 因此后续如果要用 LGA 代替全层 sweep，应按模型结构和模态分别校准，不能把同一个 LGA 指标跨 visual/text、跨架构直接套用。

### 7.1 视觉编辑层与视觉压缩方式
- LLaVA-v1.5 是 MLP projector 线性投影型，visual generality 的真实峰值在 layer 7，属于浅层偏前位置。
- Qwen2.5-VL 是 ViT + MLP/Merger 型，visual generality 的真实峰值在 layer 4，raw visual LGA Top5 为 `0, 1, 3, 2, 4`，同样偏浅层。
- BLIP2 是 Q-Former 型，visual generality 在 layer 8/9/12/15/16/21 形成平台，整体更接近中层。
- InstructBLIP 是 instruction-aware Q-Former 型，visual generality 最佳在 layer 12，也支持 Q-Former 型视觉编辑层偏中层的假设。

### 7.2 视觉编辑层与文本编辑层是否分离
- InstructBLIP 分离最清楚：visual generality layer 12，text generality layer 0。
- BLIP2 的 visual generality 是中层平台，text core 在 layer 16/17，二者有重叠但最佳指标轴不完全一致。
- LLaVA 的 visual/text generality 都指向 layer 7；但 visual core 是 layer 16，text core 是 layer 7，说明“分离”需要按 metric axis 报告，不能只看 generality。
- Qwen2.5-VL 的真实 text sweep 已回填：text generality 与 CoreAvg4 均为 layer 0，visual generality 为 layer 4，visual CoreAvg4 为 layer 8。二者同属浅层区域，但按最佳层仍存在 text 更靠前、visual 稍后的分离。

### 7.3 编辑层与 decoder size
- BLIP2-OPT-2.7B 与 InstructBLIP-Vicuna-7B 都是 Q-Former 系，visual best 均偏中层；这更像视觉压缩方式的影响，而不是 decoder size 单独决定。
- LLaVA-v1.5-7B 与 Qwen2.5-VL-7B 都是非 Q-Former / MLP-Merger 类连接方式，visual best 分别为 layer 7 与 layer 4，均偏浅层，支持连接方式/视觉压缩方式是更强解释变量。
- LLaVA-v1.5-7B 与 InstructBLIP-Vicuna-7B decoder size 接近，但 visual best 从 layer 7 变为 layer 12，进一步说明连接方式/视觉压缩方式比 decoder size 更能解释层位差异。
- 当前 7B 档位模型增多后，结构信号比大小信号更清楚；decoder size 相关性仍需 LLaVA-13B、InstructBLIP-13B 或 Qwen2.5-VL-3B/32B 补点。

## 8. 后续对齐分析入口
- 对 LLaVA / BLIP2 / InstructBLIP / Qwen2.5-VL，§6.4 已完成 raw / calibrated LGA 指标与真实 sweep 的 Spearman、Top-K hit 对齐。
- Qwen2.5-VL text adapter 真实 sweep 已回填并纳入 §6.4；其 text LGA Top3 为 `0, 1, 2`，命中真实 text generality/CoreAvg4 layer 0，但相关性因大面积高分平台而不显著。
- 对结构假设，当前最稳的比较是：MLP/Merger 型 LLaVA/Qwen2.5-VL 视觉编辑层偏浅，Q-Former 型 BLIP2/InstructBLIP 视觉编辑层偏中层。
- 下一步建议把 §6.4 的模型内相关性改写为论文结果表，并补充更多架构点验证 metric 是否跨模型稳定。

### 11.5 与 §6.4 GPT 版本交叉验证

Claude 独立计算结果与 §6.4 GPT 版本完全一致（rho 值差异 < 0.001，属浮点精度范围）。两个版本的主要结论对齐：

1. **视觉编辑**：LLaVA 的 `M_newn_x_1mcos` 是最强 Gen 预测指标（rho=0.884），Top3 精确命中 layer 7；BLIP2 需要 `M_abscos_x_newn`（rho=0.464）定位中层平台；Qwen2.5-VL 的 `M_cos`（rho=0.512）Top3 含 layer 4；InstructBLIP visual 无指标能精确定位 Gen peak layer 12。
2. **文本编辑**：InstructBLIP text 的 `M_dot`（rho=0.796）同时命中 Gen layer 0 和 Core layer 2，是最可靠的文本编辑层预测指标；Qwen2.5-VL text 的 Top3 命中 layer 0 但 rho 不显著（p=0.45）；LLaVA text 所有指标的 Top3 都偏向 0/1/2 而真实最优在 layer 7，存在系统性偏差。
3. **Locality 追踪**：`M_dot` 在多数模型上与 Locality 强正相关（LLaVA visual rho=0.86, InstructBLIP visual rho=-0.91 反向），说明 raw dot 更像 locality/后层信号而非 generality 信号。
4. **Portability 注意**：LLaVA text / InstructBLIP text / Qwen2.5-VL text 的 Portability 几乎为常数（所有层相同），导致 rho=NA 或不可解释。

### 11.6 综合建议

- 如果要用 LGA 代替全层 sweep 选择编辑层，必须按模型架构和模态分别校准指标，不能跨模型直接套用。
- 视觉编辑层选择：MLP/线性投影型优先看 `M_newn_x_1mcos` 或 `M_cos`；Q-Former 型优先看 `M_abscos_x_newn`。
- 文本编辑层选择：优先看 `M_dot` 或 `M_new_norm` 的 Top-K，但需注意 LLaVA text 存在系统性偏差（LGA 偏最浅层而真实最优在 layer 7）。
- CoreAvg4 的预测比单轴 Generality 更难：多数模型上没有单一 LGA 指标能同时预测 Gen 和 Core，因为 Core 是 Gen/Loc/Port 的平均，而 Loc 与 Gen 往往反向。
