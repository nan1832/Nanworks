## 2. 公式（v3）

```
F' = { l : S_v_cos(l) > 0 }                                              # E-VQA: F' = layers 0–27
M_rel(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^1.8             l ∈ F'
M_gen(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^2.5             l ∈ F'
M_loc(l) = max(0, S_v_cos(l)) × √S_v_new_norm(l) × (l/30)^2              l ∈ F'
M_avg(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^2               l ∈ F'
```

死区（OOF）：layers {28, 29, 30}（cos < 0）。

## 7. 数据量 ablation 结论

### 7.1 候选层与数据量的关系

**Top1 候选层（layer 18）与梯度计算样本数无关**。在 1000 与 6345 两个数据规模下，四个指标（Rel / Gen / Loc / Avg）的 Top1 全部稳定指向 layer 18，Top3 集合完全一致。

### 7.2 数据量影响的实际表现

数据量从 1000 增加到 6345 带来的变化是：

1. **绝对得分系统性提升约 10%**（pilot M_rel 峰值 0.0247 vs full 0.0273），因为 pilot 的 cos 系统性低 0.008–0.015
2. **排序 Spearman ≥ 0.985**，仅在中段（layers 12–22 的内部排序）有 1–2 层的边界扰动
3. **死区分界完全一致**（layer 28 cos 翻负的位置不变）
4. **OOF 集合完全一致**（层 {28, 29, 30}）

### 7.3 工程意义

| 决策 | 影响 |
| --- | --- |
| 用 pilot 1000 决定编辑层 | 与 full 6345 推荐结果完全等价（Top3 全相同）|
| 用 pilot 1000 决定深度因子 α | 鲁棒，拐点位置不依赖样本量 |
| 用 pilot 1000 估死区门槛（cos > 0）| 稳定，pilot 与 full 的死区分界一致 |
| **省下的成本** | 6345/1000 ≈ 6.3 倍梯度采集时间 |

**建议**：在新数据集上做 LGA 推荐层 sweep 时，pilot 1000 已经足够定位 Top3 候选层；只在需要做最终绝对得分对比或显著性检验时再扩到 full 规模。

### 7.4 边界注意

- 当数据集规模小于 ~500 时未验证，cos 估计方差可能进一步放大，Top1 稳定性有待测试
- 当 LGA 曲线没有明显单峰（如 InstructBLIP visual 浅层 cos 已平台化）时，pilot/full 的 Top 漂移可能更大，本结论仅在 BLIP2 E-VQA 形态下成立
