# LLaVA E-VQA 视觉模态 LGA 推荐层（pilot 1000，v3 公式）

生成时间：`2026-05-27`

## 1. 任务

把 [BLIP2_EVQA_Visual_LayerPrediction_v2_claude.md](BLIP2_EVQA_Visual_LayerPrediction_v2_claude.md) §11 的 v3 修正公式应用到 **LLaVA-v1.5-7b** 在 E-VQA pilot 1000 上的视觉模态 LGA 数据，预测 Rel / Gen / M-Loc / Average 的候选层。

数据源：`downloads/Temp/evqa_request_only_llava_lga_candidate_20260525/pilot_1000/virtual_delta_h_lga_layer_scores.csv`

- 模型：`llava-v1.5-7b`（LLM decoder 32 层，编号 0–31）
- n_request = 1000
- visual token 范围：1–576
- Layer 31 `S_v_zero_grad=True`，排除
- 有效层：0–30（共 31 层）

## 2. 公式（v3 沿用）

```
F' = { l : S_v_cos(l) > 0 }
M_rel(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^1.8       l ∈ F'
M_gen(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^2.5       l ∈ F'
M_loc(l) = max(0, S_v_cos(l)) × √S_v_new_norm(l) × (l/30)^2        l ∈ F'
M_avg(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l/30)^2         l ∈ F'
```

## 3. LLaVA 与 BLIP2 的几何对比

| 维度 | BLIP2 E-VQA visual (full) | LLaVA E-VQA visual (pilot 1k) |
| --- | --- | --- |
| 浅层 cos | 0.13 平台（0–17） | **0.27 平台**（0–17，约 BLIP2 的 2 倍） |
| cos 单调性 | 浅层平台 → 中段下降 → layer 28+ 翻负 | **全程为正**，深层（24–30）反而升至 0.29 |
| new_norm 趋势 | 0.89 → 0.09 单调递减 | **0.49 → 0.006 更陡的指数衰减** |
| 死区（cos<0） | 存在：{28, 29, 30} | **不存在**（所有层 cos>0）|
| F' 大小 | 28 层（0–27） | 31 层（0–30，全可行） |

**关键差异**：LLaVA 没有 BLIP2 那种"深层方向反对齐"的死区，因此 v3 公式在 LLaVA 上不会自动剔除任何层。深度因子 `(l/30)^α` 会推动得分向深层倾斜，但被 LLaVA 极陡的 new_norm 衰减压制。

## 7. 关键观察

### 7.1 Rel / Gen / Avg 三个指标 Top1 = layer 16

LLaVA-v1.5-7b LLM 部分（32 层 decoder）中段 layer 16 是 cos×new_norm × 深度因子 同时较大的位置。三个指标 Top3 集合高度重合：{15, 16, 17}。

### 7.2 M-Loc Top1 漂到 layer 24（与 BLIP2 完全不同）

LLaVA 深层（24, 26, 27, 30）出现 **cos 反弹至 0.29** 的现象——明显高于浅层平台 0.27。结合 √new_norm 软压缩 + 深度因子 (l/30)^2 推力，M-Loc 的最高分落在 **layer 24**。

候选解释：
- LLaVA 后期 decoder 层可能与编辑目标在表征空间天然对齐（answer projection 阶段）
- 这种"假性高 cos"也可能是 LLaVA 7B 浅层激活范数大、深层激活范数小，导致归一化后的 cos 在深层数值偏大

由于无 LLaVA E-VQA 实测 ground truth，**M-Loc Top1=24 需要 sweep 验证**。如果验证为假性 locality（编辑根本写不进去），则需在 LLaVA 上加 `new_norm > threshold` 二次门槛。

### 7.3 与 Bridge30 LLaVA 推荐对比

Bridge30 LLaVA visual 实测最佳层（来自 [Bridge30_RequestOnly_PerTarget_LGA_Predictor_claude.md](Bridge30_RequestOnly_PerTarget_LGA_Predictor_claude.md)）：

| 目标 | Bridge30 真实 Best | E-VQA v3 预测 Top1 | 偏差 |
| --- | ---: | ---: | --- |
| Generality | 7 | **16** | +9 层 |
| Locality | 26 | **24** | -2 层 |
| Combined3 | 26 | **16**（Avg） | -10 层 |

Bridge30 的 Generality 最佳层在 layer 7（浅层），而 E-VQA v3 公式预测 Generality Top1=16（中层）。这是因为 v3 公式带 `(l/30)^2.5` 的强深度偏好，会自然把推荐推向中后段。**两个数据集任务难度不同**：Bridge30 是 request-only 验证，编辑信号不需要深层语义；E-VQA 全量需要更深层的语义抽象。

Locality Top1 在两个数据集上比较接近（24 vs 26），说明"深层弱编辑→locality 好"的规律在 LLaVA 上跨数据集稳定。

### 7.4 没有 OOF 死区

LLaVA E-VQA pilot 1000 全部 31 个非 zero_grad 层 cos 都 > 0，F' = layers 0–30，没有 BLIP2 那种深层"方向反对齐"的死区。这是 LLaVA 几何与 BLIP2 的实质差异。

## 8. 实操建议

1. **首选编辑层**：Rel / Gen / Avg 取 **layer 16**（次选 15 或 17）
2. **M-Loc 双轨验证**：先尝试 layer 17 / 18（中层稳健候选），同时跑 layer 24（深层候选）做 sweep 对照；选择真实 M-Loc 最高且 Rel 不崩盘的一层
3. **联合候选层**：覆盖 4 个目标的 Top3 并集 = **{15, 16, 17, 19, 20, 24}**，工程上对这 6 层做 sweep 即可定位 LLaVA E-VQA 实际最佳编辑层
4. **不建议**：layer 0–8（深度因子太小，泛化弱）；layer 28–30（编辑容量耗尽，new_norm < 0.02）

## 9. 局限

- 没有 LLaVA E-VQA 编辑实测 ground truth，本预测尚未事后验证（论文 VEAD Table 2 是 BLIP2-OPT-2.7B 的结果，不能直接套到 LLaVA）
- v3 公式的 α 参数（1.8 / 2 / 2.5）原本是在 BLIP2 BLIP2 E-VQA 上调的，对 LLaVA 的最优 α 未单独 fit
- LLaVA 深层 cos 反弹现象（layers 24+）是否对应真实编辑能力，还是数值假象，需 sweep 验证；如为假象，需补充 `new_norm > 0.05` 之类的二次门槛
- pilot 1000 vs full（如有）的稳定性需另行 ablation；BLIP2 上 ρ_s≈0.99，LLaVA 上预期类似但未验证
