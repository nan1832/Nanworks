# BLIP2 E-VQA 视觉模态各指标预测公式与 Top 层（修正版 v2）

生成时间：`2026-05-27`

## 1. 背景与方法论修正

上一版 [BLIP2_EVQA_Visual_LayerPrediction_claude.md](BLIP2_EVQA_Visual_LayerPrediction_claude.md) 直接套用 Bridge30 推得的"取极值 / 反排"公式，结果 Generality Top1=0、Locality/Average Top1=30，与论文 VEAD Table 2 实测最佳层 **layer 19** 完全错位。

本版基于三条核心观察重新设计公式：

1. **真实编辑曲线是单峰凸函数**：浅层欠拟合（容量过剩但缺乏语义抽象），深层失效（梯度方向反转 + 编辑死区），最佳层位于 60% 深度附近
2. **必须同时满足两个门槛**：`S_v_cos > 0`（方向对齐）+ `S_v_new_norm` 足够大（编辑能写进去）
3. **需要深度权重**：浅层即便满足门槛也不够泛化，必须用 `(l/L_max)^α` 这类单调上升因子推向深层

数据源：`downloads/Temp/evqa_request_only_blip2_lga_candidate_20260525/full/virtual_delta_h_lga_layer_scores.csv`

- L_max = 30（layer 31 zero_grad 排除）
- 死区识别：`cos < 0.08` OR `new_norm < 0.20` 的层
  - E-VQA 上死区 = layers 23–30（layer 23 cos=0.049 已塌；layer 28–30 cos<0 反对齐）

## 2. 通用编辑可行性域 F

```
F = { l : 0 ≤ l ≤ 22, S_v_cos(l) > 0.08, S_v_new_norm(l) > 0.25 }
```

E-VQA BLIP2 visual 上 F = {0, 1, 2, ..., 22}（共 23 层）。

所有四个目标的预测都先限定在 F 内，再用各自公式排序。

## 3. 四个目标的预测公式

### 3.1 Request (Rel) — 编辑可写性主导

**理论**：Rel 衡量"能否把新事实写入"，对方向对齐和梯度幅度同时敏感，深度需求中等（要够深才能编码新事实，但不需要最高语义抽象）。

```
M_rel(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l / 30)^1.8       l ∈ F
```

### 3.2 Generality (T-Gen / M-Gen) — 语义抽象主导

**理论**：泛化要求新事实表示能迁移到改写、释义、相关问句，必须落在已完成语义抽象的深层。深度权重比 Rel 更强。

```
M_gen(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l / 30)^2.5       l ∈ F
```

### 3.3 Locality (M-Loc) — 编辑收敛性主导

**理论**：M-Loc 在 E-VQA 上同样是单峰（浅层扰动过广、深层伤害模型）。需要在可行域内挑选"梯度幅度已显著衰减"（编辑不会广泛传播）但仍保留对齐的层。用 `√new_norm` 软压缩高幅度。

```
M_loc(l) = max(0, S_v_cos(l)) × √S_v_new_norm(l) × (l / 30)^2        l ∈ F
```

T-Loc 在所有层=100.00，无判别意义，不预测。

### 3.4 Average — Rel/Gen/Loc 几何平均的中心位置

**理论**：三个目标的 Top1 都在 layer 18–19，Average 直接取 `(l/30)^2` 这个"折中"指数。

```
M_avg(l) = max(0, S_v_cos(l)) × S_v_new_norm(l) × (l / 30)^2         l ∈ F
```

## 7. 公式设计理由

### 7.1 为什么需要可行性域 F

直接套用 `S_v_new_norm` 反排会把 Top1 推到 layer 30，但 layer 30 的 `S_v_cos = -0.0265`（方向反对齐）+ `new_norm = 0.089`（仅为 layer 19 的 17.5%），导致编辑根本写不进去（Rel=86.22 崩盘）。

F 的设计是"先排除编辑死区，再排序"。

### 7.2 为什么用 `(l / L_max)^α` 而不是反排

E-VQA 的 `M_abscos_x_newn` 与 `S_v_new_norm` 沿层数都是**单调下降**：

- `M_abscos_x_newn`：0 处 0.118 → 22 处 0.034 → 单调减
- `S_v_new_norm`：0 处 0.887 → 22 处 0.350 → 单调减

任何对单调函数取 Top 都会落到端点（layer 0 或 layer 30），无法识别真实的单峰最佳层。`(l / L_max)^α` 这个递增因子与单调递减的几何特征相乘，才能产生中段峰值。

### 7.3 α 的选择（per target）

| α | 峰值位置 | 适用目标 |
| ---: | ---: | --- |
| 1.0 | layer 15 | 浅层偏好（不用） |
| 1.5 | layer 17 | — |
| 1.8 | layer 17–18 | **Rel**（中等深度需求） |
| 2.0 | layer 18 | **Average / M-Loc**（折中） |
| 2.5 | layer 18 | **Generality**（强深度需求） |
| 3.0 | layer 18 | — |
| ≥4.0 | layer 22 | 极深度偏好（超调） |

α=1.8 至 2.5 区间对应的峰值都在 layer 17–19，与论文实测 layer 19 高度吻合。α 在该区间不敏感，鲁棒。

### 7.4 为什么 M-Loc 用 `√new_norm` 不用 `new_norm`

直接 `cos × new_norm × (l/30)²` 在 layer 18 的得分最大，但对 layer 22（cos×nn=0.034，深度因子 0.538）的处罚过重。`√new_norm` 软压缩了高幅度的"过强编辑"，让中后段的"小但精准"编辑获得更高 M-Loc 分。实际效果是把 layer 22 的 M_loc 排名从第 7 推到第 4，更符合 M-Loc 单峰但右翼比 Gen 平缓的真实形态。

## 8. 实操建议

1. **首选编辑层 = layer 18 或 19**（任选其一；论文用 19，本预测推 18）
2. **次选 Top3**：{18, 19, 17}，工程上可全部尝试取最佳
3. **明确避开**：layer ≥ 23（cos 已塌或反向；编辑死区）；layer ≤ 10（深度不足，泛化弱）
4. **跨数据集泛化时**：
   - 重新计算 F 的两个门槛（`cos > 0.5 × max_cos` 或固定 0.08）
   - 保留 `(l / L_max)^α` 的结构，α 可在 [1.8, 2.5] 内复用
   - 若数据集 cos 几何与 E-VQA 不同（如 InstructBLIP 浅层 cos 已很高），需再次校准 α 或改用 cos-elbow 检测

## 9. 局限与未来工作

- 本版公式仅在 1 个数据集（E-VQA）× 1 个模型（BLIP2-OPT-2.7B）的 7 个采样点上事后验证，α 的选取偏经验。
- Top1=18 与实测候选 Top1=19 偏差 1 层，但 layer 18 未被论文测量。需补做 layer 16/17/18/20/21/22 的实测扫层确认 18 vs 19 谁更优。
- 公式假设 cos 曲线存在"高位平台 + 拐点 + 塌陷"的三段结构；对没有明显平台的数据集（如 InstructBLIP visual cos 全程低位）需另设方案。
- Bridge30 上推得的"反排"系列指标在真实编辑场景失效，提示后续 LGA 指标研究必须区分"可行性域内的相对排序"与"包含死区的全局排序"。

### 11.9 v3 仍未完全匹配论文的两点差距

1. **layer 25 在论文排第 3，v3 排第 20–21**：根本原因是 layer 25 的 LGA 信号（cos=0.020, new_norm=0.242）与编辑效果（Avg=95.80）严重背离。任何基于 cos×new_norm 的公式都无法把 layer 25 推到 Top3，需要引入完全不同的信号源（如 attention pattern、神经元激活分布）才能修复。
2. **M-Loc 的 layer 30 应排第 5，v3 仍归 OOF**：论文里 layer 30 M-Loc=85.98 高于 layer 10（85.83）和 layer 0（84.51），是因为 cos<0 导致编辑写不进去 → 模型未受扰动 → 局部性"假性变好"。这不是真正的 locality 优势，所以 v3 把 layer 30 归 OOF 在工程上更合理（不会推荐这层）。
