## 0. 总体研究目标与约束

### 0.1 核心研究问题

在第一阶段确定的视觉 Adapter 插入层上，通过引入编辑诱导的外部知识图谱，验证：

1. 相关知识子图能否提高 MMKE 官方 1-hop Portability；
2. 图结构编码（RGCN）是否优于无图 Adapter、平铺三元组和等规模随机图；
3. Portability 提升是否以牺牲 Reliability、Generality、Locality 为代价。

### 0.2 方法边界

**借鉴 GLAME**：
- 围绕编辑主体实体构建局部关联子图
- 使用 RGCN 融合实体与关系信息

**区别于 GLAME**：
- 编辑视觉语言模型，非纯文本 LLM
- 在语言解码器视觉 token 位置插入 Adapter，非 FFN 秩一更新
- 目标知识与关联知识均作为视觉表征残差注入
- 批量联合训练共享编辑器，非单次编辑独立优化
- 必须通过 MMKE 编辑后指标验证

### 0.3 固定实验决定

| 决定项 | 取值 | 确认来源 |
|---|---|---|
| 首轮模型 | BLIP2-OPT-2.7B | 研究设计 |

```python
import re
from typing import Dict, List, Tuple

def extract_subject_and_edits(item: Dict) -> Tuple[str, str, List[Dict]]:
    """
    从 alt 字段提取主体实体和编辑点
    
    返回：
        subject: 主体实体名称
        subject_type: 实体类型
        edit_points: 编辑点列表（属性-值对）
    """
    alt_text = item['alt']
    
    # 提取主体实体（第一句）
    match = re.search(r'The (.*?) in the image corresponds to (.*?)\.', alt_text)
    if match:
        subject_type = match.group(1).strip()
        subject = match.group(2).strip()
    else:
        # 回退策略：使用 type_self
        subject_type = item['type_self']
        subject = None
    
    # 提取编辑点（启发式规则 + NER）
    edit_points = []
    
    # 示例规则：location/origin
    origin_match = re.search(r'from (.*?),', alt_text)
    if origin_match:
        edit_points.append({
            'relation': 'origin',
            'object': origin_match.group(1).strip()
        })
    
    # 示例规则：formed_in
    formed_match = re.search(r'formed in (\d{4})', alt_text)
    if formed_match:
        edit_points.append({
            'relation': 'inception',
            'object': formed_match.group(1)
        })
    
    return subject, subject_type, edit_points
```

```python
# scripts/p2_entity_linking.py

import requests
from SPARQLWrapper import SPARQLWrapper, JSON

def link_entity_to_wikidata(entity_name: str, entity_type: str = None) -> List[Dict]:
    """
    使用 Wikidata API 搜索实体
    
    返回候选 QID 列表，按相关性排序
    """
    # Wikidata Search API
    url = "https://www.wikidata.org/w/api.php"
    params = {
        "action": "wbsearchentities",
        "format": "json",
        "language": "en",
        "search": entity_name,
        "limit": 10
    }
    
    response = requests.get(url, params=params)
    results = response.json().get("search", [])
    
    # 过滤：优先匹配 entity_type
    candidates = []
    for r in results:
        candidates.append({
            "qid": r["id"],
            "label": r["label"],
            "description": r.get("description", ""),
            "score": r.get("match", {}).get("type", "")
        })
    
    return candidates

def get_wikidata_neighbors(qid: str, hop: int = 1) -> List[Dict]:
    """
    获取实体的 Wikidata 邻域
    
    返回三元组列表：[(subject_qid, property_id, object_qid), ...]
    """
    sparql = SPARQLWrapper("https://query.wikidata.org/sparql")
    query = f"""
    SELECT ?property ?propertyLabel ?object ?objectLabel WHERE {{
      wd:{qid} ?p ?object .
      ?property wikibase:directClaim ?p .
      SERVICE wikibase:label {{ bd:serviceParam wikibase:language "en". }}
    }}
    LIMIT 100
    """
    
    sparql.setQuery(query)
    sparql.setReturnFormat(JSON)
    results = sparql.query().convert()
    
    triples = []
    for result in results["results"]["bindings"]:
        triples.append({
            "subject": qid,
            "relation": result["propertyLabel"]["value"],
            "relation_id": result["property"]["value"].split("/")[-1],
            "object": result["objectLabel"]["value"],
            "object_qid": result["object"]["value"].split("/")[-1] if "/entity/" in result["object"]["value"] else None
        })
    
    return triples
```

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import dgl
from dgl.nn.pytorch import RelGraphConv

class RGCN(nn.Module):
    """
    关系图卷积网络，编码混合编辑图
    
    参考 GLAME 实现，适配 MMKE-Entity 混合图
    """
    def __init__(
        self,
        num_nodes: int,
        num_rels: int,
        h_dim: int,  # 隐藏维度，从 dev_val 选择
        num_bases: int,  # basis 分解数，从 dev_val 选择
        num_hidden_layers: int = 2,  # 从 dev_val 选择 [1,2,3]
        dropout: float = 0.2,
        activation=F.rrelu,  # GLAME 使用 rrelu
    ):
        super().__init__()
        self.num_nodes = num_nodes
        self.h_dim = h_dim
        self.num_rels = num_rels
        self.num_bases = num_bases
        self.num_hidden_layers = num_hidden_layers
        self.dropout = dropout
        
        # 构建 RGCN 层
        self.layers = nn.ModuleList()
        for i in range(num_hidden_layers):
            self.layers.append(
                RelGraphConv(
                    h_dim, h_dim, num_rels,
                    regularizer='basis',
                    num_bases=num_bases,
                    activation=activation,
                    self_loop=True,
                    dropout=dropout
                )
            )
    
    def forward(self, g, node_features, edge_types):
        """
        参数：
            g: DGL 图
            node_features: [num_nodes, h_dim]
            edge_types: [num_edges] 关系类型 ID
        
        返回：
            node_outputs: [num_nodes, h_dim]
        """
        h = node_features
        for layer in self.layers:
            h = layer(g, h, edge_types)
        return h
```

```python
# editor/graph_encoder/graph_projector.py

class GraphProjector(nn.Module):
    """
    将图编码器输出投影到语言模型维度，并融合到 Adapter
    """
    def __init__(self, graph_dim: int, llm_dim: int, fusion_beta: float = None):
        super().__init__()
        # 投影层：graph_dim → llm_dim
        self.projection = nn.Sequential(
            nn.Linear(graph_dim, llm_dim),
            nn.LayerNorm(llm_dim)
        )
        
        # 融合系数 β（可学习或固定）
        if fusion_beta is None:
            self.beta = nn.Parameter(torch.tensor(0.5))  # 可学习
        else:
            self.register_buffer('beta', torch.tensor(fusion_beta))  # 固定
    
    def forward(self, graph_repr, adapter_input):
        """
        参数：
            graph_repr: [b, graph_dim] 主体实体的 RGCN 输出
            adapter_input: [b, llm_dim] Adapter 的编辑信号
        
        返回：
            fused_input: [b, llm_dim] 融合后的编辑信号
        """
        graph_proj = self.projection(graph_repr)  # [b, llm_dim]
        fused = adapter_input + self.beta * graph_proj
        return fused
```

**验收条件**：
- 投影维度匹配
- β 参数可学习或固定（根据配置）

```python
# 将子图三元组平铺为文本序列，用 BERT 编码后拼接

class FlatTripleEncoder(nn.Module):
    def __init__(self, bert_model_name="bert-base-uncased", llm_dim=2560):
        super().__init__()
        from transformers import BertModel
        self.bert = BertModel.from_pretrained(bert_model_name)
        self.projection = nn.Linear(768, llm_dim)
    
    def forward(self, triples_text):
        """
        参数：
            triples_text: List[str]，每个样本的三元组拼接文本
                例如："Pixies origin Manchester. Pixies member Blaine Fincher. ..."
        
        返回：
            flat_repr: [b, llm_dim]
        """
        # BERT 编码
        bert_outputs = self.bert(**self.tokenizer(triples_text, return_tensors="pt", padding=True))
```

```python
# scripts/p7_statistical_analysis.py

from scipy.stats import wilcoxon
from statsmodels.stats.multitest import multipletests
import numpy as np

def bootstrap_paired_ci(scores_a, scores_b, n_bootstrap=10000, alpha=0.05):
    """
    样本级配对 bootstrap 置信区间
    
    参数：
        scores_a, scores_b: 逐样本得分（长度相同）
    
    返回：
        mean_diff, ci_lower, ci_upper
    """
    diffs = np.array(scores_a) - np.array(scores_b)
    n = len(diffs)
    
    bootstrap_means = []
    for _ in range(n_bootstrap):
        idx = np.random.choice(n, n, replace=True)
        bootstrap_means.append(diffs[idx].mean())
    
    mean_diff = diffs.mean()
    ci_lower = np.percentile(bootstrap_means, 100 * alpha / 2)
    ci_upper = np.percentile(bootstrap_means, 100 * (1 - alpha / 2))
    
    return mean_diff, ci_lower, ci_upper

# 主分析：G3 vs G1 的 Portability
port_g3 = load_per_sample_scores('g3', 'Port', seed=42)
port_g1 = load_per_sample_scores('g1', 'Port', seed=42)

mean_diff, ci_low, ci_high = bootstrap_paired_ci(port_g3, port_g1)
print(f"G3 - G1 Portability: {mean_diff:.2f} [{ci_low:.2f}, {ci_high:.2f}]")

# Wilcoxon 符号秩检验
stat, p_value = wilcoxon(port_g3, port_g1)
print(f"Wilcoxon p-value: {p_value:.4f}")

# 多重比较校正（Holm）
comparisons = [
    ('g3_vs_g1', p_g3_g1),
    ('g3_vs_g2', p_g3_g2),
    ('g3_vs_g4', p_g3_g4),
    ('g3_vs_g5', p_g3_g5),
]

p_values = [p for _, p in comparisons]
reject, p_corrected, _, _ = multipletests(p_values, method='holm')

for (name, p_orig), p_corr, rej in zip(comparisons, p_corrected, reject):
    print(f"{name}: p={p_orig:.4f} → p_corr={p_corr:.4f}, reject={rej}")

# Reliability/Locality 非劣效检验
def non_inferiority_test(scores_new, scores_baseline, margin=2.0):
    """
    非劣效检验：验证新方法不比基线差超过 margin
    
    H0: new < baseline - margin（劣效）
    H1: new >= baseline - margin（非劣效）
    """
    mean_diff, ci_low, ci_high = bootstrap_paired_ci(scores_new, scores_baseline)
    
    # 如果 CI 下界 > -margin，则非劣效
    is_non_inferior = ci_low > -margin
    
    return is_non_inferior, mean_diff, ci_low, ci_high

# Reliability 非劣效检验（margin=2pp）
rel_non_inf, rel_diff, rel_ci_low, rel_ci_high = non_inferiority_test(
    load_per_sample_scores('g3', 'Rel'),
    load_per_sample_scores('g1', 'Rel'),
    margin=2.0
)

print(f"Reliability non-inferiority: {rel_non_inf}")
print(f"  Diff: {rel_diff:.2f} [{rel_ci_low:.2f}, {rel_ci_high:.2f}]")
```

**统计协议**：
- **主分析**：样本级配对 bootstrap 95% CI（n=10000）
- **辅助**：Wilcoxon 符号秩检验
- **多重比较**：Holm 校正
- **非劣效界**：Reliability/Locality margin = 2pp
- **3 seeds**：报告均值、标准差、逐 seed 结果
- ❌ **禁止**：放宽到 p<0.1；用 p>0.05 证明无下降

```python
def generate_multihop_question(sample, subgraph, hop_count=2):
    """
    生成多跳 Portability 问题
    
    要求：
        1. 问题必须依赖编辑后的反事实根边
        2. gold route 可追溯
        3. 答案唯一且无歧义
    """
    # 1. 定位编辑根边
    edit_edge = find_edit_edge(subgraph)  # 例如 (Pixies, origin, Manchester)
    
    # 2. 从新对象扩展 1-hop
    new_object = edit_edge['target']  # Manchester
    next_edges = get_neighbors_from_wikidata(new_object)  # (Manchester, country, UK)
    
    # 3. 构建 2-hop 推理链
    gold_route = [
        edit_edge,           # (Pixies, origin, Manchester) [编辑边]
        next_edges[0]        # (Manchester, country, UK) [真实边]
    ]
    
    # 4. 生成问题（模板或 GPT-4）
    question = f"What country is the {sample['type_self']} in the image from?"
    answer = next_edges[0]['target']  # UK
    
    return {
        'port_type': f'{hop_count}-hop',
        'Q&A': {
            'Question': question,
            'Answer': answer
        },
        'gold_route': gold_route,
        'source_triples': [
            {'source': 'edit', 'triple': edit_edge},
            {'source': 'wikidata', 'triple': next_edges[0]}
        ]
    }
```

### 每个新模型必须重新审计的 7 项

**不能只替换模型名和 visual span**，必须逐项重新审计。原始命令第七部分第 2 项列出 7 个审计维度：

| 审计项 | 说明 | 输出 | 证据要求 |
|---|---|---|---|
| **1. 图像 token 定位** | 视觉 token 在序列中的位置（前缀/中间/多段） | `visual_tokens.span_start/span_end` | 实际前向一次并打印索引 |
| **2. 层编号** | 语言模型层的实际路径模板与索引范围 | `layer_prefix`, `num_layers` | 从模型 `named_modules()` 实测 |
| **3. hidden size** | 语言模型隐藏维度 | `hidden_size` | 从 `model.config` 读取 |
| **4. attention mask** | 视觉 token 的 mask 处理方式 | mask 构造逻辑 | 打印 mask 张量形状与取值 |
| **5. hook 语义** | post-block / pre-block，输出格式（tuple/tensor） | `hook_point.location/format` | 见下方"hook 语义"约束 |
| **6. generation 配置** | 生成参数（max_length, beam, sampling） | generation config | 必须与第一阶段评测一致 |
| **7. 第一阶段 Ours Top-1** | 该模型的定位结果（**必须来自第一阶段实测，不得推断**） | `edit_layer.ours_top1` | 指向第一阶段 evidence 文件 |

**标题更正说明**：前一版本标题写"6 项"但表内实际列出 7 行，标题与内容不符。原始命令第七部分第 2 项明确列举 7 个维度（图像 token 定位、层编号、hidden size、attention mask、hook 语义、generation 配置、第一阶段 Ours Top-1），标题已改为 7 项。

**hook 语义约束（承接附录 E.1.4）**：

BLIP2 首轮已核验为 **post-block**（`vead.py` L171 `register_forward_hook`，改写 `outpt[0]`）。对每个新模型必须重新确认：

- 该模型 decoder block 的 `forward` 返回值是 tuple 还是 tensor；若为 tuple，隐状态是否位于 `[0]`；
- 是否存在与 BLIP2 不同的残差/LayerNorm 顺序（pre-LN vs post-LN），影响 Adapter 注入点的语义；
- ❌ 禁止假定所有模型的 hook 语义与 BLIP2 相同；
- ❌ 禁止用 `register_forward_hook` 冒充 pre-block 注入（原始命令第二部分第 6 项）。

**第 7 项特别约束**：

`edit_layer.ours_top1` 必须引用第一阶段该模型的实际 evidence 文件（结果 json / checkpoint tsv），并在 P9 报告中记录文件路径与层号。BLIP2 自身的层号目前仍存在冲突（见附录 E.1.5【P0阻塞项】），因此：

- 在 BLIP2 层号未澄清前，**禁止**将任何"L0"或"L1"结论推广到新模型；
- 每个新模型的 Top-1 层号必须独立取自其第一阶段 evidence，不得按 BLIP2 结论类推。

**审计未通过时的处理**：

| 情况 | 处理 |
|---|---|
| 无法定位视觉 token span | 该模型退出 P9，记录原因 |
| 第一阶段无该模型 Ours 定位结果 | 该模型退出 P9，不得用启发式层号替代 |
| hook 语义与 BLIP2 不同 | 允许继续，但必须在结果表中标注语义差异 |
| generation 配置无法对齐 | 允许继续，但 G1/G3 必须使用同一配置，并标注与 BLIP2 的差异 |

**L0 hook 状态说明（重要）**：

`vead.py` L267-268 存在注释：

```
# Layer-0 input edit runs as a forward pre-hook, before TraceDict can
# retain layer-0 input in its forward hook. The caller already passes
# layer-0 inputs in llm_inpt, so run directly instead of reading
# td[layer0].input, which does not exist yet for L0.
```

对该注释的核验结论：

1. 该注释位于 `infer_from_mid_layer()` 内 `mid_inpt_layer_i == 0` 分支，描述的是 **`TraceDict` 无法 retain L0 输入** 这一现象，其代码动作是"直接调用 `get_llm_outpt`"，**并未注册任何 pre-hook**。
2. 全仓 `grep -rn "forward_pre_hook\|register_forward_pre" --include=*.py` 的命中全部位于 `utils/nethook.py`（L113-154，`Trace`/`TraceDict` 的通用实现），**Adapter 挂载路径（`init_hook_adaptors`）不经过该实现**。
3. 因此：**当前证据不能证明第一阶段存在真正的 L0 Adapter `forward_pre_hook` 分支**。Adapter 注入在所有 `edit_layers` 上统一为 post-block。

**据此约束**：
- ❌ 禁止将 Adapter 注入描述为 pre-block 或 block 输入注入。
- ❌ 禁止用普通 `register_forward_hook` 冒充 `pre_block` 语义（对应原始命令第二部分第 6 项）。

**边方向说明（重要）**：`build_graph.py` L74 为

```python
edges = [(node_indices[v], node_indices[u]) for u, v in edges]
```

而 L63 追加的是 `(subject_str, target_str)`。解包 `for u, v` 得 `u=subject, v=target`，构造出的边为 `(target, subject)`。即**消息在图上从 target 流向 subject**，使 subject 节点能聚合其新对象及新对象邻域的信息——这与 `compute_v.py` 只取 subject 节点输出（见 E.2.4）在语义上一致。本项目若照搬 RGCN，必须复现该方向，否则 subject 收不到任何邻域消息。

**自环说明**：自环由 `dgl.add_self_loop` 在 L87 显式添加，且发生在 `g.edata['etype']` 赋值（L85）**之后**、`ndata['norm']` 计算（L88-91）**之前**。因此自环边不在 `etype` 张量覆盖范围内，但计入入度归一化。另有一层自环在 `UnionRGCNLayer` 内部通过 `loop_weight` 实现（见 E.2.3），两者并存。
