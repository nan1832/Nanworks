# P2动态图结构人工审核说明

本页用于完成手册附录B要求的50条独立图结构审核。对象Q-ID已在上一轮审核，不需要重复判断。

入口：`http://127.0.0.1:8772/?v=1`

每条只检查三件事：

1. “主体 → 关系 → 新值”是否正确表达页面所示样本的`pred→alt`变化；
2. 若焦点新对象有Wikidata现实邻域，邻域是否都从该新对象节点出发；
3. 是否存在明显的主体错误、根边遗漏、错误对象或断开的图结构。

无需逐条核验Wikidata邻域事实本身，也无需重新搜索Q-ID。页面中的机器完整性检查已覆盖端点存在、方向、作用域、活动节点连通性和评测字段隔离。

- 正常：点“结构合理”。
- 发现明确问题：选择问题类型，点“有问题”，并写简短备注。
- 无法判断：点“不确定”并说明原因。
