## 0. 研究主线与不可变更约束

### 0.1 主线（本轮不变）

1. 第一阶段用 Ours-Direct 定位视觉编辑 Adapter 插入层；
2. 第二阶段**固定定位结果**，引入目标知识注入与相关知识图谱注入；
3. 首轮：MMKE-Entity × BLIP2-OPT-2.7B；
4. Ours-Direct Top-3 = L0 / L1 / L2，主实验用 Top-1 = **L0**；
5. L1 / L2 **只能**用于预先声明的层敏感性实验，或独立 validation 选择；
6. 禁止使用 official eval/test 重新选层；
7. 基础 VLM 全部冻结，只训练新增编辑模块；
8. 融合形式固定为 $H'_v = H_v + \Delta H_{target} + \beta \cdot \Delta H_{KG}$。

### 0.2 本轮不做的事

- 不重新设计与主线无关的方案；
- 不复现 GLAME（GLAME 是 ROME 式秩一权重更新 + per-edit 重置的 RGCN，与本项目的”共享可训练视觉 Adapter”是两种编辑范式，见 §3.4）；
- 不把 GLAME 论文的数字、超参、结论搬运为本项目结论。

### 1.1 Adapter 真实结构（更正 v2.0）

【已由项目代码验证】`VisionEditAdaptor` **不是** v2.0 描述的 "down_proj + ReLU + up_proj + LayerNorm 零初始化 bottleneck"。真实结构是**图像 token 对编辑信号的交叉注意力残差**：

```
img_reps = layer_outpt[:, vt_begin:vt_end]                      # [b, N_q, d]
x  = mlp_begin(ln_img_reps(img_reps))                           # [b, N_q, mid]
q  = cross_att_q_mlp(x)                                         # -> h heads
k  = cross_att_k_mlp(ln_edit_reps(edit_reps))                   # [b, l_edit, mid]
v  = cross_att_v_mlp(ln_edit_reps(edit_reps))
s  = softmax(q·kᵀ/sqrt(mid/h) + (edit_mask-1)*9999999999)
x  = mlp_end(s·v) * inf_map                                     # inf_map = sigmoid(InfluenceMapper(...))
layer_outpt[:, vt_begin:vt_end] = img_reps + x
```

**由此产生的三条强制修正**：

1. v2.0 的"Adapter 零初始化恒等性测试（diff < 1e-5）"**不适用**。第一阶段用 `reset_parameters()`（标准 `nn.Linear` 初始化），编辑前的恒等由 `open_adaptor(False)` 开关保证。
2. 因此 v2.0 关于"所有 Adapter 参数第一步均有非零梯度""零初始化时 down_proj 无梯度"的整套论述**已删除**，P0 梯度检查改为 §5.5。
3. Adapter 的编辑信号来自 `get_edit_signal_for_one_request`：把 `(prompt, image, target_new)` 拼成完整输入跑一遍冻结模型，取**同一编辑层的输出表征**。第二阶段的 $\Delta H_{KG}$ 必须与该信号**并列**，不得替换它。

### 1.2 "Influence Mapper" 归属更正（v2.0 重大错误）

- v2.0 把它写成"**3 层全连接 + Sigmoid**"的本研究门控，并暗示与 GLAME 有关。
- 事实一【由GLAME源码确认】：GLAME 源码**不存在**任何 Influence Mapper 模块，也没有视觉 token 门控；图输出直接整体加到 subject token 的 MLP 输出上，只有 `clamp_norm_factor` 范数裁剪。
- 事实二【已由项目代码验证】：`InfluenceMapper` 是**第一阶段 VEAD 已有模块**，结构为 `LayerNorm×2 → BaseResMapper×2 → 多头 einsum 点积 → 头维均值 / sqrt(d/h)`，**不是三层全连接**；由 `cfg.IT.add_it` 开关控制，并有独立训练目标（`rg_relative_inf_loss + rg_up_loss + l_down_loss`，权重 `inf_mapper_lambda`）。

**结论**：复用第一阶段 `InfluenceMapper` 于 $\Delta H_{target}$ → 标注【已由项目代码验证】；若为 $\Delta H_{KG}$ 另建门控（输入含 $z_G$），必须标注 **"本研究新设计"**，并设无门控消融 **G5**。

### 1.3 Hook 语义更正（v2.0 确定性错误）

【已由项目代码验证】`init_hook_adaptors` 使用 `edit_layer.register_forward_hook(...)`，改写的是 **block 输出**（output tuple 第 0 项）。

- v2.0 `model_registry.yaml` 的 `hook_point.location: "pre_block"` **是错的，已删除**；
- "L0" 的确切语义 = `language_model.model.decoder.layers.0` 的 **forward 输出**被 Adapter 改写；
- 第二阶段必须沿用同一 `llm_layer_tmp = "language_model.model.decoder.layers.{}"` 与同一 `register_forward_hook` 语义。若将来确需在 block 输入注入，必须显式用 `register_forward_pre_hook` 或包装层，并声明这与第一阶段语义不同，**不得用 `forward_hook` 冒充 `pre_block`**。

> 附注：`vead.py` 中 "Layer-0 input edit runs as a forward pre-hook" 的注释处理的是**训练缓存的 mid-layer 起点**（`mid_inpt_layer_i==0` 时 `TraceDict` 拿不到 layer0 的 input），与 Adapter 注入位置无关，不要误读。

### 2.1 GLAME 十二项必答核验结论

| # | 核验项 | 结论（附源码位置） |
|---|---|---|
| 1 | 围绕哪个实体建子图 | 围绕**新对象 `target_new`（o\*）**。`extract_subgraph.py:95-109` 用 `rewrite["target_new"]["id"]` 取邻域，再拼入编辑根边 `(subject, relation, target_new)`。**不是**围绕 subject |
| 2 | 三元组字段与方向 | `{"subject","relation","target"}`（`init_triples_dict`），语义方向 subject → target |
| 3 | 反转 / 反向边 / 自环 | **反转**：`build_graph.py:74` `edges = [(node_indices[v], node_indices[u]) for u, v in edges]`，DGL 实际边为 target→subject，使消息汇向 subject；**无反向边**；**有自环**：`dgl.add_self_loop(g)`（`:87`），自环边不带 `etype/r_h`，由 DGL 补零 |
| 4 | 关系类型编号 | `relation_to_id = {rel: idx for idx, rel in enumerate(set(...))}`（`:32-33`）：按 `set` 遍历序、**每条编辑请求局部重新编号** → 跨样本不稳定、跨运行不保证可复现。本项目必须改为全局 `relation_vocab.json`（§7.4） |
| 5 | 初始表示来源 | 来自**被编辑的 LLM 自身**（GPT-2 XL / GPT-J），`layer_module_tmp` 的**输出**，层号 `get_repr_layer`（cf = **5**）。子词策略 hparams 为 `gnn_fact_token_strategy="avg"` → 走 `get_average_hidden_state`。**论文写 last token，代码默认 avg** |
| 6 | RGCN 真实配置 | `encoder_name='uvrgcn'` → `UnionRGCNLayer`（RE-GCN 系），**非标准 R-GCN**；`num_hidden_layers=2` 且 `build_input_layer/build_output_layer` 返回 `None` → **实际 2 层**；激活 **`F.rrelu`**（论文写 ReLU）；`num_bases=100/num_basis=100` **传入但 `UnionRGCNLayer` 内部完全未使用**（仅一个 `weight_neighbor [in,out]`）；`dropout=gnn_feat_drop`（cf 0.3 / cf_plus 0.4）；`self_loop=True`（`loop_weight` 与 `evolve_loop_weight` 双套，按入度掩码切换）；`skip_connect=False`；消息 `msg = (h_src + rel_emb[etype]) @ weight_neighbor`，聚合 `fn.sum`，`apply_func` 乘 `norm = indegree^{-1}` |
| 7 | 节点输出如何聚合 | **不做池化**。`compute_v.py:196-197` 仅取 `outputs[subject_id]` |
| 8 | 图表示如何进入 compute_u/compute_v | **`compute_u` 完全不涉及图**（纯 ROME）。`compute_v` 中 `target_delta_feature = subject_feature`，经 `edit_output_fn` 加到 `mlp_module_tmp.format(layer)` 输出的 `lookup_idx` 位置；有 `clamp_norm_factor(=4) × target_init.norm()` 裁剪；最终 `target = target_init + delta`，再解 `right_vector = (target - cur_output)/dot(cur_input, left_vector)` |
| 9 | 训练单位 | **单次编辑**。`apply_glame_to_model` 逐条 `execute_glame`；`compute_v` 内对 RGCN 做 `gnn_num_grad_steps`（cf 40 / cf_plus 35）步 AdamW，`early_stopping_loss=4e-2` |

### 2.3 GLAME 源码缺陷（本项目必须规避）

1. `extract_subgraph.py:113` `new_data["triples"].extend(origin_triplet)` —— `origin_triplet` 是 **dict**，`extend` 会展开成键字符串 `['subject','relation','target']`；`:117` `new_json.extend(new_data)` 同理。README 明确该脚本只是 "simple demonstration"，其输出与 `datasets/*_graph.json` 的实际格式不能划等号。→ **只借鉴 SPARQL 查询与三元组 schema，不复用写盘逻辑**。

- **`alt`**：编辑**后**的目标知识描述。第一阶段作为 `target_new` 用于 NLL 训练与 Rel/Gen 判定【已由项目代码验证】。

### 4.2 一条必须写进论文的结构性风险

【已由项目代码验证 + 样例核对】MMKE-Entity 的 `alt` **不是**单个 $(s,r,o^*)$ 三元组，而是**一整段含多条反事实的自由文本**。样例 1 的 `alt` 同时改写了国籍（American→British）、城市（Boston→Manchester）、四位成员名、影响流派、歌词题材、替补成员及其来源乐队。

因此：
- GLAME 的"单条 $(s,r,o,o^*)$ + 围绕 $o^*$ 取邻域"假设在 MMKE-Entity 上**不直接成立**；
- 本项目的编辑请求级子图必须支持**一条请求对应多条反事实根边**；
- v2.0 的"每样本至少 1 条编辑边"验收过弱，改为 §7.6 的覆盖率报告。

### 4.3 数据划分规则（修正 v2.0）

v2.0 只按 `type_self` 分层并用 `train_test_split`，同一实体的多张图可能跨集合造成泄漏。

v2.1 规则（优先级降序）：

1. **group key（主）**：按"编辑事实根"分组，按以下优先级取第一个可得者：
   a. 链接成功的主体 QID；
   b. `alt` 首句 "The {type} in the image corresponds to **{Entity}**." 抽出的实体名（正则，§7.1）；
   c. `image` 路径去掉 `+N` / `_N` 后缀的基名（如 `entity/Secret (South Korean group)+12.jpg` → `Secret (South Korean group)`）。
2. **group split**：同一 group 的所有样本必须落在同一子集。
3. **分层（次）**：在 group 约束下用 `type_self` 近似分层（`StratifiedGroupKFold` 或贪心装箱）。
4. 某 `type_self` 的 group 数 < 2 时合并为 `other`，并在报告中列出。

**必须输出的泄漏检查**（表 7）：group 交集、image 基名交集、`src` 完全一致率、`alt` 前 100 字符交集、`port_new` 问题文本交集；并对 **dev_\* 与 official eval** 做同样五项。

# data/io_utils.py 【适配伪代码】
def load_records(path):
    """自动识别 JSON 数组与 JSONL；返回 List[dict]。"""
    with open(path, 'r', encoding='utf-8') as f:
        head = f.read(4096); f.seek(0)
        if head.lstrip().startswith('['):
            return json.load(f)
        records = []
        for ln, line in enumerate(f, 1):
            line = line.strip()
            if not line:
                continue
            try:
                records.append(json.loads(line))
            except json.JSONDecodeError as e:
                raise ValueError(f'{path}:{ln} 既非 JSON 数组也非合法 JSONL: {e}')
        return records
```

# 2) 可训练模块检查（不做"所有参数第一步都非零梯度"的断言）
for mname, m in editor.get_modules_for_training().items():
    got = [n for n, p in m.named_parameters()
           if p.grad is not None and torch.isfinite(p.grad).all()]
    assert len(got) > 0, f'{mname} 完全没有有限梯度'
```

**冻结范围（不可放宽）**：整个基础 VLM，**包括 L0 原始参数**。【已由项目代码验证】`set_train` 无条件执行 `vllm.model.eval(); vllm.model.requires_grad_(False)`。第二阶段除新增图模块外，**不得**解冻任何基础参数。
