### 0.1 核心研究问题

在第一阶段确定的视觉 Adapter 插入层上，通过引入“现实基础图 + 样本级反事实编辑覆盖层”，验证：

1. 反事实编辑根边与新对象真实邻域组成的动态子图，能否提高 MMKE 官方 1-hop Portability；
2. 图结构编码（RGCN）是否优于无图 Adapter、平铺三元组、仅现实KG、仅编辑根边和等规模随机图；
3. 图谱是否提升未直接用于训练的`rel_* / m_rel_* / port_new`关联问答，而不仅是记住完整`alt`；
4. Portability与关联泛化提升是否以牺牲 Reliability、Generality、Locality 为代价。

### 0.1.1 动态编辑图的唯一语义定义（v2.1-r1新增）

MMKE-Entity的`pred`是数据集固定的原始实体知识描述，`alt`是包含反事实属性的编辑目标；`image`和`image_rephrase`是同类型替换实体图片。发布JSON不包含目标主体的原始正确图片字段。因此本研究不得把Wikidata现实邻域直接当作编辑后的目标图，也不得把`alt`反事实写回全局真实图谱。

对每条样本定义：

```text
G_real：来自Wikidata/静态快照的现实基础图
Δ_edit(sample_id)：由pred→alt事实差分得到的反事实新增/替换边
G_edit(sample_id) = G_real ⊕ Δ_edit(sample_id)
```

`⊕`表示样本作用域覆盖：同一`(subject, relation)`的旧对象只在当前`edit_context_id`中失活，新对象边标记为`counterfactual`；无关真实边继续保留。所有节点、边必须记录`source`、`truth_status`、`sample_id/edit_context_id`和证据文本跨度。

图谱的主要泛化路径是：第一跳服从`Δ_edit`，后续跳使用新对象在`G_real`中的真实邻域。例如John Stewart样本中，`John Stewart --design_based_on--> Denzel Washington`是反事实编辑边，`Denzel Washington --birth_year--> 1954`是真实基础边。

### 0.2 方法边界

**借鉴 GLAME**：
- 围绕编辑后的新对象构建局部关联子图，并把编辑根边连接回主体
- 使用 RGCN 融合实体与关系信息

**区别于 GLAME**：
- 编辑视觉语言模型，非纯文本 LLM
- 在语言解码器视觉 token 位置插入 Adapter，非 FFN 秩一更新
- 目标知识与关联知识均作为视觉表征残差注入
- 在636条训练样本上训练共享图模块；第一阶段Adapter与InfluenceMapper冻结，不执行逐请求现场优化
- 必须通过 MMKE 编辑后指标验证
- 必须显式区分现实边、反事实编辑边、虚拟节点和样本级视觉映射
- `pred`只用于P2事实差分和身份消歧，不作为训练标签；`rel_* / m_rel_* / port_new`只用于评测，不得用于构图或训练

### P2-A：冻结主体身份

```json

  "edit_context_id": "...",

  "new_evidence_span": "...",

```

执行要求：

1. 先按句子和实体类型生成候选，再做关系归一化；正则只能作为候选生成器，不能作为最终事实证据。

```python
# editor/graph_encoder/rgcn.py
# 参考 GLAME: gnn/rrgcn.py + rgcn/model.py

import torch
import torch.nn as nn
import torch.nn.functional as F
import dgl
from dgl.nn.pytorch import RelGraphConv

class RGCN(nn.Module):
    """
    关系图卷积网络，编码混合编辑图
    
    参考 GLAME 实现，适配 MMKE-Entity 混合图
    """
    def __init__(
        self,
        num_rels: int,
        h_dim: int,  # 隐藏维度，正式评测前预注册固定
        num_bases: int,  # basis 分解数，正式评测前预注册固定
        num_hidden_layers: int = 2,  # 正式评测前预注册固定
        dropout: float = 0.1,
        activation=F.rrelu,  # GLAME 使用 rrelu
    ):
        super().__init__()
        self.h_dim = h_dim
        self.num_rels = num_rels
        self.num_bases = num_bases
        self.num_hidden_layers = num_hidden_layers
        self.dropout = dropout
        
        # 构建 RGCN 层
        self.layers = nn.ModuleList()
        for i in range(num_hidden_layers):
            self.layers.append(
                RelGraphConv(
                    h_dim, h_dim, num_rels,
                    regularizer='basis',
                    num_bases=num_bases,
                    activation=activation,
                    self_loop=True,
                    dropout=dropout
                )
            )
    
    def forward(self, g, node_features, edge_types):
        """
        参数：
            g: DGL 图
            node_features: [num_nodes, h_dim]
            edge_types: [num_edges] 关系类型 ID
        
        返回：
            node_outputs: [num_nodes, h_dim]
        """
        h = node_features
        for layer in self.layers:
            h = layer(g, h, edge_types)
        return h
```

```python
# editor/graph_encoder/graph_projector.py

class GraphProjector(nn.Module):
    """
    将图编码器输出投影到语言模型维度，并融合到 Adapter
    """
    def __init__(self, graph_dim: int, llm_dim: int, fusion_beta: float = None):
        super().__init__()
        # 投影层：graph_dim → llm_dim
        self.projection = nn.Sequential(
            nn.Linear(graph_dim, llm_dim),
            nn.LayerNorm(llm_dim)
        )
        
        # 融合系数 β（可学习或固定）
        if fusion_beta is None:
            self.beta = nn.Parameter(torch.tensor(0.5))  # 可学习
        else:
            self.register_buffer('beta', torch.tensor(fusion_beta))  # 固定
    
    def forward(self, graph_repr, adapter_input):
        """
        参数：
            graph_repr: [b, graph_dim] 主体实体的 RGCN 输出
            adapter_input: [b, llm_dim] Adapter 的编辑信号
        
        返回：
            fused_input: [b, llm_dim] 融合后的编辑信号
        """
        graph_proj = self.projection(graph_repr)  # [b, llm_dim]
        fused = adapter_input + self.beta * graph_proj
        return fused
```

**验收条件**：

- β 参数可学习或固定（根据配置）
- 融合后梯度流通畅

```python
from dataset.mmke_entity import MMKEEntity
import dgl
import torch

class GraphEnhancedVEAD(VEAD):
    """
    图增强编辑器 G3：Adapter + RGCN + 融合
    """
    def __init__(self, config, graph_config):
        super().__init__(config)

        # G1是第一阶段L0 epoch-24冻结编辑器；P4禁止更新BLIP2、Adapter和InfluenceMapper
        for parameter in self.vllm.model.parameters():
            parameter.requires_grad_(False)
        for adaptor in self.adaptors.values():
            for parameter in adaptor.parameters():
                parameter.requires_grad_(False)

        # 冻结语言模型产生2560维节点初始表示，仅训练输入投影层
        self.node_input_projector = torch.nn.Linear(
            config.hidden_size, graph_config['rgcn_hidden_dim']
        )
        
        # 初始化 RGCN
        self.rgcn = RGCN(
            num_rels=graph_config['runtime_num_rels'],
            h_dim=graph_config['rgcn_hidden_dim'],  # 预注册固定值
            num_bases=min(
                graph_config['rgcn_num_bases'], graph_config['runtime_num_rels']
            ),
            num_hidden_layers=graph_config['rgcn_layers'],  # 预注册固定值
            dropout=graph_config['rgcn_dropout']
        )
        
        # 初始化投影器
        self.graph_projector = GraphProjector(
            graph_dim=graph_config['rgcn_hidden_dim'],
            llm_dim=config.hidden_size,
            fusion_beta=graph_config.get('fusion_beta')  # None=可学习
        )
        
        # 独立优化器（图模块）
        self.graph_optimizer = torch.optim.AdamW(
            list(self.node_input_projector.parameters())
            + list(self.rgcn.parameters())
            + list(self.graph_projector.parameters()),
            lr=graph_config['graph_lr'],  # 预注册固定值
            weight_decay=1e-4
        )
    
    def forward_with_graph(self, batch_data, subgraphs):
        """
        前向传播，融合图知识
        
        参数：
            batch_data: 编辑样本批次
            subgraphs: 每个样本对应的子图
        """
        # 1. 批量编码子图
        graph_reprs = []
        for i, g in enumerate(subgraphs):
            # 提取主体实体 ID
            subject_id = g['subject_node_id']
            
            # RGCN 前向
            # 节点文本先由冻结BLIP2/OPT编码，再投影到1024维；梯度只进入新投影层
            with torch.no_grad():
                frozen_node_features = self.encode_node_texts(g['node_texts'])
            node_features = self.node_input_projector(frozen_node_features)
            node_outputs = self.rgcn(
                g['dgl_graph'],
                node_features,
                g['edge_types']
            )  # [num_nodes_i, h_dim]
            
            # 提取主体表示（参考 GLAME compute_v.py L196）
            subject_repr = node_outputs[subject_id]  # [h_dim]
            graph_reprs.append(subject_repr)
        
        graph_reprs = torch.stack(graph_reprs)  # [b, h_dim]
        
        # 2. 原始 Adapter 编辑信号（第一阶段已实现）
        adapter_input = self.get_edit_signal(batch_data)  # [b, llm_dim]
        
        # 3. 融合图知识
        fused_signal = self.graph_projector(graph_reprs, adapter_input)  # [b, llm_dim]
        
        # 4. 设置融合后的编辑信号到 Adapter
        self.adaptor.set_edit_signal(fused_signal, ...)
        
        # 5. 正常前向推理
        return self.vllm.forward(...)
    
    def train_step(self, batch_data, subgraphs):
        """训练一步；只优化新图模块，冻结G1不得产生梯度或参数版本变化。"""
        # 前向 + 损失计算
        loss, loss_dict = self.compute_loss_with_graph(batch_data, subgraphs)
        
        # 反向传播
        self.graph_optimizer.zero_grad()  # 图模块优化器
        loss.backward()
        self.graph_optimizer.step()

        self.assert_frozen_g1_unchanged()
        
        return loss, loss_dict
```

```python
class FlatTripleEncoder(nn.Module):
    def __init__(self, bert_model_name="bert-base-uncased", llm_dim=2560):
        super().__init__()
        from transformers import BertModel
        self.bert = BertModel.from_pretrained(bert_model_name)
        self.projection = nn.Linear(768, llm_dim)
    
    def forward(self, triples_text):
        """
        参数：
            triples_text: List[str]，每个样本的三元组拼接文本
                例如："Pixies origin Manchester. Pixies member Blaine Fincher. ..."
        
        返回：
            flat_repr: [b, llm_dim]
        """
        # BERT 编码
        bert_outputs = self.bert(**self.tokenizer(triples_text, return_tensors="pt", padding=True))
        cls_repr = bert_outputs.last_hidden_state[:, 0, :]  # [b, 768]
        
        # 投影到 LLM 维度
        flat_repr = self.projection(cls_repr)  # [b, llm_dim]
        return flat_repr
```

```python
# 构建随机图：保持节点数、边数、度分布，但随机置换边连接

def build_random_graph(original_graph):
    """
    从原始图生成随机对照图
    
    保持：
        - 节点数
        - 边数
        - 入度/出度分布
    
    随机化：
        - 边的源节点和目标节点连接
    """
    import networkx as nx
    
    # 转换为 NetworkX
    G_orig = dgl.to_networkx(original_graph)
    
    # 保持度序列的随机化
    G_random = nx.configuration_model([d for n, d in G_orig.degree()])
    G_random = nx.Graph(G_random)  # 移除多重边和自环
    G_random.remove_edges_from(nx.selfloop_edges(G_random))
    
    # 转回 DGL
    g_random = dgl.from_networkx(G_random)
    
    # 复用原始节点特征和关系类型（随机打乱关系分配）
    g_random.ndata['feat'] = original_graph.ndata['feat']
    g_random.edata['etype'] = torch.randperm(g_random.num_edges()) % original_graph.edata['etype'].max()
    
    return g_random

# 对每个子图生成随机版本
```

```python
# scripts/p7_statistical_analysis.py

from scipy.stats import wilcoxon
from statsmodels.stats.multitest import multipletests
import numpy as np

def bootstrap_paired_ci(scores_a, scores_b, n_bootstrap=10000, alpha=0.05):
    """
    样本级配对 bootstrap 置信区间
    
    参数：
        scores_a, scores_b: 逐样本得分（长度相同）
    
    返回：
        mean_diff, ci_lower, ci_upper
    """
    diffs = np.array(scores_a) - np.array(scores_b)
    n = len(diffs)
    
    bootstrap_means = []
    for _ in range(n_bootstrap):
        idx = np.random.choice(n, n, replace=True)
        bootstrap_means.append(diffs[idx].mean())
    
    mean_diff = diffs.mean()
    ci_lower = np.percentile(bootstrap_means, 100 * alpha / 2)
    ci_upper = np.percentile(bootstrap_means, 100 * (1 - alpha / 2))
    
    return mean_diff, ci_lower, ci_upper

# 主分析：G3 vs G1 的 Portability
port_g3 = load_per_sample_scores('g3', 'Port', seed=42)
port_g1 = load_per_sample_scores('g1', 'Port', seed=42)

mean_diff, ci_low, ci_high = bootstrap_paired_ci(port_g3, port_g1)
print(f"G3 - G1 Portability: {mean_diff:.2f} [{ci_low:.2f}, {ci_high:.2f}]")

# Wilcoxon 符号秩检验
stat, p_value = wilcoxon(port_g3, port_g1)
print(f"Wilcoxon p-value: {p_value:.4f}")

# 多重比较校正（Holm）
comparisons = [
    ('g3_vs_g1', p_g3_g1),
    ('g3_vs_g2', p_g3_g2),
    ('g3_vs_g4', p_g3_g4),
    ('g3_vs_g5', p_g3_g5),
]

p_values = [p for _, p in comparisons]
reject, p_corrected, _, _ = multipletests(p_values, method='holm')

for (name, p_orig), p_corr, rej in zip(comparisons, p_corrected, reject):
    print(f"{name}: p={p_orig:.4f} → p_corr={p_corr:.4f}, reject={rej}")

# Reliability/Locality 非劣效检验
def non_inferiority_test(scores_new, scores_baseline, margin=2.0):
    """
    非劣效检验：验证新方法不比基线差超过 margin
    
    H0: new < baseline - margin（劣效）
    H1: new >= baseline - margin（非劣效）
    """
    mean_diff, ci_low, ci_high = bootstrap_paired_ci(scores_new, scores_baseline)
    
    # 如果 CI 下界 > -margin，则非劣效
    is_non_inferior = ci_low > -margin
    
    return is_non_inferior, mean_diff, ci_low, ci_high

# Reliability 非劣效检验（margin=2pp）
rel_non_inf, rel_diff, rel_ci_low, rel_ci_high = non_inferiority_test(
    load_per_sample_scores('g3', 'Rel'),
    load_per_sample_scores('g1', 'Rel'),
    margin=2.0
)

print(f"Reliability non-inferiority: {rel_non_inf}")
print(f"  Diff: {rel_diff:.2f} [{rel_ci_low:.2f}, {rel_ci_high:.2f}]")
```

**统计协议**：
- **主分析**：样本级配对 bootstrap 95% CI（n=10000）
- **辅助**：Wilcoxon 符号秩检验
- **多重比较**：Holm 校正
- **非劣效界**：Reliability/Locality margin = 2pp
- **3 seeds**：报告均值、标准差、逐 seed 结果
- ❌ **禁止**：放宽到 p<0.1；用 p>0.05 证明无下降

### 预注册研究假设

**H1**：G3 的 1-hop Portability 显著高于 G1
- 判定规则：bootstrap 95% CI 下界 > 0，且 Holm 校正后 p < 0.05

**H2**：G3 优于 G2（图结构编码优于平铺）
- 判定规则：同上

**H3**：G3 优于 G4（真实图优于随机图）
- 判定规则：同上

**H4**：G3 的 Reliability/Locality 非劣于 G1
- 判定规则：bootstrap 95% CI 下界 > -2pp

**注意**：H1-H4 是**研究假设**，不是验收条件。负结果同样有价值，必须保存和分析。

- 在 BLIP2 层号未澄清前，**禁止**将任何"L0"或"L1"结论推广到新模型；

```python
def analyze_graph_quality(indices, subgraphs):
    """

    """
    stats = {
        'avg_num_nodes': [],
        'avg_num_edges': [],
        'virtual_node_ratio': [],
        'has_edit_edge': [],
        'subject_degree': [],
    }

        g = subgraphs[i]
        stats['avg_num_nodes'].append(g['num_nodes'])
        stats['avg_num_edges'].append(g['num_edges'])
        
        virtual_count = sum(1 for n in g['nodes'].values() if n['source'] == 'virtual')
        stats['virtual_node_ratio'].append(virtual_count / g['num_nodes'])
        
        stats['has_edit_edge'].append(1 if g['has_edit_edge'] else 0)
        stats['subject_degree'].append(g['subject_degree'])
    
    return {k: np.mean(v) for k, v in stats.items()}
```

**边方向说明（重要）**：`build_graph.py` L74 为

```python
edges = [(node_indices[v], node_indices[u]) for u, v in edges]
```

而 L63 追加的是 `(subject_str, target_str)`。解包 `for u, v` 得 `u=subject, v=target`，构造出的边为 `(target, subject)`。即**消息在图上从 target 流向 subject**，使 subject 节点能聚合其新对象及新对象邻域的信息——这与 `compute_v.py` 只取 subject 节点输出（见 E.2.4）在语义上一致。本项目若照搬 RGCN，必须复现该方向，否则 subject 收不到任何邻域消息。

**自环说明**：自环由 `dgl.add_self_loop` 在 L87 显式添加，且发生在 `g.edata['etype']` 赋值（L85）**之后**、`ndata['norm']` 计算（L88-91）**之前**。因此自环边不在 `etype` 张量覆盖范围内，但计入入度归一化。另有一层自环在 `UnionRGCNLayer` 内部通过 `loop_weight` 实现（见 E.2.3），两者并存。

### F.12 v2.1→v2.1-r1反事实覆盖图修订（2026-09-18）

本次修订纠正了“现实KG直接等于编辑后知识”这一不充分表述，并将研究流程统一为：

1. `pred`是数据集固定的编辑前原始知识，`alt`是包含反事实属性的编辑目标；二者必须共同用于P2事实差分。
2. `G_real`保存现实知识；`Δ_edit(sample_id)`保存反事实新增/替换事实；模型实际读取`G_edit(sample_id)=G_real⊕Δ_edit(sample_id)`。
3. 事实第一跳服从反事实编辑，后续跳围绕新对象读取现实邻域；旧冲突边只在当前编辑上下文失活，不修改全局Wikidata缓存。
4. `rel_* / m_rel_* / port_new`全部隔离为评测字段，不参与训练、构图、划分或邻居选择。
5. 新增RealOnly、EditOnly-0hop、Overlay-1hop、Overlay-2hop和RandomMatched控制，避免仅凭`alt`复现率宣称图谱提高了泛化。
6. P1的508/128仍是图片连通分组候选；P2冻结主体Q-ID与事实根ID后必须重新构建连通分量并重划。
7. P3在新dev划分上的G1是第二阶段开发基线，与第一阶段原协议严格复现分开报告。

设计依据边界：GLAME支持“围绕编辑后的新对象扩展局部图”的思路；样本级覆盖、视觉别名、字段隔离与上述控制实验属于本研究新增设计，不能归因于GLAME源码。
