# 第二阶段实体构图审核

本目录是只读实验数据的审核副本，不修改冻结图谱、模型或训练队列。

入口：`index.html`（构建后可直接双击，离线可用）。

## 使用

1. 双击 `index.html`，使用 Edge 或 Chrome。无需联网、无需启动服务、不占服务器 GPU。
2. 左侧切换 **正式评测集 955 条 / 官方训练集 636 条**。可搜索实体名、原文关键词或 `#10` 这样的零基索引；可筛选有真实邻域、无编辑根边和未审核记录。
3. 左侧数据区切换完整原始 JSON、pred/alt 对照、逐句差异和原始图片。右侧图可拖节点、平移、缩放；点击节点、关系边或事实行查看原文与来源。
4. 四种图分开展示：G3 Overlay1hop、EditOnly0hop、RealOnly，以及 G4 RandomMatched。默认事实箭头是主体→客体，消息方向开关显示实际 `edge_src→edge_dst`；两者相反。
5. 自环默认不绘制，但完整保留在运行时 JSON 和全部边表。未入图事实默认不叠加；开启后为红色虚线，明确不属于模型实际图。没有根边的样本也保留，不补造关系。
6. 在“人工审核”填写结论与意见，自动暂存本浏览器。完成一批后点“导出审核意见”保存 JSON。导入仅接受本版本的样本；已存在的本地意见不会被导入覆盖。
7. 可点“导出本条证据”，保存原始记录、四版图、事实、断句及数据哈希。意见不会改动任何冻结数据。

## 图片边界

内置评测 #10、#14 两张既有审计图片；其他图片不会联网下载或按实体名错误替换。可在“原始图片”页选择本机 `data_image` 文件夹，按 `entity/xxx` 原始路径读取；不上传。图片文件名与编辑目标可能不同，按原始记录显示。

## 数据与完整性

- 训练集原始 `entity_train.json` 是从既有共享项目只读复制的官方文件，SHA256 与冻结配置一致。
- 评测集使用此前同步的官方 `entity_eval.json`，SHA256 与冻结配置一致。
- 构建验证 26 个输入文件，包含四版训练运行时缓存、四版评测运行时缓存、原始数据、事实与来源图。预期哈希可用的文件须完全一致才能生成网页。
- 对 1,591 条记录逐一核对索引、样本 ID、pred/alt、节点数与边数组；断句产物核对只忽略首尾空白，网页中的原始 JSON 不改值。
- 评测图：4,329 条共识事实，1,541 条明确过滤；21 条记录有真实邻域，28 条无编辑根边。
- 训练图：636 条记录，Overlay 共 8,585 个节点、8,379 条语义边；最大单图 **678 节点 / 724 语义边**，全部保留。
- 训练事实表仅包括冻结高置信子集，不冒充完整抽取候选集。评测问答仅供事后审核，不用于补边、训练或重建正式评测图。
- 大图远景自动隐藏密集标签，但不删除节点或边；放大或点击查看完整内容。

详细数据校验：`data-verification.json`。浏览器测试：`browser-verification.json`；截图 `preview-*.png`。

## 文件

`index.html`、`review.css`、`review.js`、`review-data.js` 必须放在同一目录，移动或分享时请一起复制。全量证据数据约 72 MB，首次打开请稍等。

`node build.mjs` 从冻结源文件重新生成数据包（不会改变源文件）。`python qa.py` 使用既有本机 Playwright 与 Edge 做离线交互测试；测试意见只存在临时浏览器配置中，不进入用户审核记录。
