# 任务差异与定位公式：本轮执行计划

日期：2026-09-26。目的：检验数据集/模型条件下梯度方向是否异质，以及混合汇总是否掩盖定位方法差异。本轮只读取现有数据、日志和评测结果，不启动训练，不修改原公式，不按测试结果修补训练配置。

1. 核验 MMEdit/E-VQA 与 MMKE-Bench 的官方定义，并读取本项目实际 train 样本；分开记录编辑对象、反事实构造、当前模型输出与目标一致性、答案长度。
2. 对7模型×3数据集每层统计平均视觉梯度余弦、正内积样本比例、零梯度/无效层、浅中深变化、有效样本覆盖。旧/新均为完整答案平均NLL梯度，旧答案来自model_pred。检查服务器是否保存逐样本方向，缺失时不能伪造负方向比例、分布或置信区间。
3. 以新范数、绝对余弦×新范数、(1−余弦)×新范数、带符号投影、余弦、内积、深度平方×范数等已有指标为机制对照；纯负方向项作为可弃权诊断。固定公式后分数据集/模型分析层排名相关性，拆看Rel/T-Gen/M-Gen/T-Loc/M-Loc/Average及Top-1/Best@3/Mean@3。缺失层不记零、不移除后补选。
4. 保留2026-09-25冻结结果，并增设纳入2026-09-26 PaliGemma原main中断评测的实际运行口径；stable不混入main。旧clean口径仅作稳健性对照。
5. 对有共同候选结果的固定组合，按模型留一：统一选择器用其余模型所有数据集选择公式；任务选择器只用其余模型同一数据集选择公式；同时与固定纯新范数比较。此为已看过数据的回顾性稳健性检验，不称独立确认。报告差值、覆盖和选择稳定性，不只报告胜率。
6. 交付报告、21组合逐层方向图、机器可读明细、可复现脚本、来源哈希及后续最小验证计划。只有现有证据支持时才建议按任务分公式。

## 执行结果

上述现有数据分析已完成：服务器21组合归档与本地原始CSV一致，统计597个有效层条目；核验全部样本目标、三个数据集字段及官方定义；完成8种机制对照、分项相关性、任务分层与留一模型比较。126项历史Top-K核对及247项实际结果指标复核通过。原实验台账和训练配置未修改。

发现的关键数据缺口：正式21组合逐样本日志没有保存dot/cos/norm，只有答案和损失；因此精确的逐样本方向分层需要后续补算。本轮完成了已有逐层平均余弦与正内积比例的分析，没有把未执行的补算记为完成。完整结论和后续最小诊断见《三数据集_方向关系与任务条件定位分析.md》。
